Examples: fold and monoid in Scala

The code of the foldable page: fold with foldLeft and foldRight, and the reduction with a monoid done in two steps (first map, then concatenate). Checked with Scala 3.8.4 and the course options. The real foldMap is the course exercise: it is not here.

The whole file

Run it with scala-cli run Foldable.scala. It uses two different monoids on the same type of list: the maximum of integers and the concatenation of strings.

The output

To remember

A fold over a monoid does not depend on the order of the elements, nor on how they are grouped.
To compute a foldMap by hand: map on the list with the function, then concatenate with the monoid of the target type.
