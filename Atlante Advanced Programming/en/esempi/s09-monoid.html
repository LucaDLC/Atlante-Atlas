Examples: monoid in Scala

The code of the theory page, in a file that compiles and runs. Every example is checked with Scala 3.8.4 and the course options (-Werror, -source:future). It does not contain the solutions of the course exercises: it uses different types and operations.

The whole file

Run it from the terminal with scala-cli run Monoid.scala. The first two lines are instructions for scala-cli: they give the Scala version and the compilation checks.

The output

Running the program shows this output. Each line corresponds to a println, in the same order.

To remember

A monoid is a type with an associative binary operation and an identity element.
The test of a law on some values does not prove the law. The course proves it with ScalaCheck, generating many values: that is why the trait has object laws with the properties.
