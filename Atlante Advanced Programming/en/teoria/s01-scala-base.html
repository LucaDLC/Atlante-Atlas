Everything is an expression

In Java you separate statements (they do something) and expressions (they are worth something). In Scala almost everything is worth something, even a whole block.

Running the code with scala-cli

All commands are run from the week's folder and end with a dot, which means "this folder".

CommandWhat it does
scala-cli compile .Just compiles. Useful to see the errors.
scala-cli test .Compiles and runs the tests of Exercises.test.scala.
scala-cli test . -wAs above, but reruns the tests on every save. The recommended way of working.
scala-cli repl .Opens the REPL with your code loaded, to try by hand.
scala-cli run . -M adpro.intro.printAbsRuns the indicated @main (-M is needed if there is more than one).
scala-cli clean .Deletes the generated files. Try this if "it worked before and now it does not".

In the REPL the functions must be called with the full name, or imported:

scala> import adpro.intro.MyModule.*
scala> abs(-7)
val res0: Int = 7

Typical errors

scala> adpro.intro.Exercise.fib(10)
value Exercise is not a member of adpro.intro
Nel package adpro.intro non esiste niente che si chiami Exercise. Controlla il nome esatto dell'object nel file (e se fib sta fuori da ogni object, si chiama adpro.intro.fib(10)). Se hai appena modificato il file, chiudi e riapri scala-cli repl .: il REPL vede il codice compilato all'avvio.

def square(n: Int): Int = return n * n compiles without errors. But return is in the list of constructs forbidden in the exercises and at the exam: write only n * n. See Rules and prohibitions.
