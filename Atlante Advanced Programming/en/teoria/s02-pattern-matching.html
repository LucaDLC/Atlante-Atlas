Pattern matching

x match asks "what shape does x have?". Each case describes a possible shape. Scala tries the cases from the top and chooses the first that matches, and meanwhile gives a name to the pieces you need.

Reading a match

From the cell itself. Cons(head: A, tail: List[A]) has two fields, in that order. The pattern Cons(h, _) lines them up with the names you choose: the first is called h, the second you throw away. You could write Cons(primo, resto) and it would be the same.

A match run case by case

Exercise 1 of week 2: what is this expression worth? You answer without running, trying the cases in order.

List(1, 2, 3, 4, 5) match
  case Cons(x, Cons(2, Cons(4, _))) => x
  case Nil => 42
  case Cons(x, Cons(y, Cons(3, Cons(4, _)))) => x + y
  case Cons(h, t) => h
  case _ => 101

Compiling this match with -Werror (the course's project.scala) Scala flags the last case: Unreachable case except for null. Every list is Nil or Cons, and case Cons(h, t) already takes them all: case _ => 101 can never fire.

What can be written in a pattern

PatternMatchesNames it creates
Nilonly the empty listnone
Cons(h, t)any cellh head, t tail
Cons(_, Nil)a list with a single elementnone
Cons(2, t)a list that starts with 2t
Cons(x, Cons(y, _))at least two elementsx, y
(Nil, _)a pair whose first piece is emptynone
_everythingnone
x (lowercase)everythingx

In patterns a lowercase name is a new name, which gets filled. A Capitalised name is a thing that must already exist (a constructor such as Nil or a constant).

Guards: case … if

After the pattern you can add a condition. The case holds only if the pattern matches and the condition is true.

Matching on two lists together

To go through two lists in parallel put the two lists in a pair and match on the pair (exercise 16).

Typical errors

All taken from real attempts at the exercises, with the message that Scala 3.8 gives.

def size[A](t: Tree[A]): Int = match
  case Leaf(_) => 1
expression expected but match found
Manca il soggetto prima di match: scrivi = t match.
case Const(h, t) => h * product(t)
no pattern match extractor named Const was found
Il costruttore si chiama Cons, senza la t. (Seguono altri errori a cascata come value * is not a member of Any: sparisce tutto correggendo il nome.)
def drop[A](l: List[A], n: Int): List[A] = l match
  case n < 0 => l
no pattern match extractor named < was found
Un pattern descrive una forma, non una condizione. Per controllare n usa un if prima del match, o una guardia: case _ if n <= 0 => l.
case Some(X) => X
Not found: X
Maiuscolo = Scala cerca una X che esiste già. Per un nome nuovo usa il minuscolo: case Some(x) => x.
def head[A](l: List[A]): A = l match
  case Cons(h, _) => h
match may not be exhaustive.
