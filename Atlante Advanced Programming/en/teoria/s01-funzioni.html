Functions as values

In Scala a function is a value like 42 or "ciao": you put it in a val, pass it to another function, return it. A function that receives or returns functions is called higher-order (higher-order function, HOF).

Writing a value, writing a function

For data you have literals: you write the value directly in the code.

val l = List(1, -2, 3)        // una lista
val a = Array(-1, 2, -3)      // un array
val z = (42, false)           // una coppia

For functions too there is a literal: the anonymous function (or lambda). It has no name; it gets one only if you put it in a val.

Passing a function to another

filter is a method of lists that receives a "yes/no" function and keeps only the elements for which the answer is yes. Whoever calls your function is filter, once per element.

x does not exist before. It is the name of the parameter of the function you wrote. The value is given by whoever calls it, here filter. It is the same thing that happens when you call abs(-3): inside abs, n is worth -3.

Three ways of writing the same function

Scala lets you shorten anonymous functions when it understands the types by itself.

List(1, 2, 3).map(_ * _)
Wrong number of parameters, expected: 1
_ * _ è una funzione a due parametri, ma map ne vuole una a uno. Per "moltiplica x per se stesso" serve il nome: map(x => x * x).
val negative = x => x < 0
Missing parameter type

I could not infer the type of the parameter x
Qui non c'è nessuna lista da cui dedurre il tipo di x. Scrivilo: (x: Int) => x < 0.
