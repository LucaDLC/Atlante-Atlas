Currying and composition

A function with two arguments can be rewritten as a function that takes one and returns another function that waits for the second. It is called currying. It serves to fix an argument once and reuse the rest.

Two arguments together, or one at a time

Together

val add2 = (x: Int, y: Int) => x + y
add2(2, 3)   // 5

Type: (Int, Int) => Int. You must give both arguments at once.

One at a time (curried)

val add = (x: Int) => (y: Int) => x + y
add(2)(3)    // 5

Type: Int => (Int => Int). Each argument has its own pair of brackets.

It works also with defs that have several parameter lists: def add(x: Int)(y: Int): Int = x + y, and then val incr = add(1) (checked with Scala 3.8).

The first argument can configure the function for the whole project, the second arrives at runtime. And often curry/uncurry serve only to make the types match when you pass a function to another that wants it in the other form.
