map2, sequence, traverse

Exercises 9–11. Three ways of combining several Options: map2 joins two, sequence turns a list of Options into an Option of a list, traverse does map and sequence together. In all of them: if even a single piece is missing, the result is None.

map2: combining two Options

1) map2 "lifts" a two-argument function into the world of Options. 2) It is a sequencer: it runs two calculations that can fail and combines the results only if both succeed.

sequence: from List[Option[A]] to Option[List[A]]

Example from the text: for each employee you have asked the database for the salary. Each answer is an Option (None if the connection dropped). You want all the salaries, or to know that something went wrong.

The text observes that sequence should not be a method of List (it would tie lists to Options) and cannot be a method of Option (its argument is a list). So it goes as a function of its own, in the file or in the companion object.

traverse: map and sequence in one pass

traverse(List(1, 2, 3))(x => if x > 0 then Some(x * 10) else None)    // Some(List(10, 20, 30))
traverse(List(1, -2, 3))(x => if x > 0 then Some(x * 10) else None)   // None

Why not sequence(as.map(f))? It gives the same result, but map knows nothing about Options: it applies f to the whole list and builds an intermediate list, even if the first element fails. traverse does everything in a single pass.
