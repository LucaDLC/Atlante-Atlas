Trees and folds on trees

Exercises 2–5 of week 3. A tree is another algebraic type: a leaf with a value, or a branch with two subtrees. You write size, maximum and map, then you discover that they are the same function: fold.

The type

It cannot happen. One does not write t.left != null: one asks the shape with match. If it is a Leaf you have the value, if it is a Branch you have both children.

size: counting the nodes

maximum: the largest value

case Branch(left, right) => size(left).max(size(right)) compares the sizes of the subtrees, not the values. It must call maximum on both.

map: same shape, values transformed

def map[A, B](t: Tree[A])(f: A => B): Tree[B] = t match
  case Leaf(value) => Leaf(f(value))
  case Branch(left, right) => Branch(map(left)(f), map(right)(f))
case Leaf(value) => value.toString()
Found:    String
Required: Tree[B]
Due problemi. 1) Non sai che f è toString: lo decide chi chiama, tu scrivi f(value). 2) Il risultato va rimesso in una foglia: Leaf(f(value)).

fold: the function that contains them all

Look at what size, maximum and map have in common: they all do something with the leaves and something to combine the two results of a branch. Only what changes.

Functiong (leaf)f (branch)Code
size1counts 1, ignores the value1 + left + rightfold[A, Int](t)((l, r) => 1 + l + r)(_ => 1)
maximum1the value itselfthe larger of the twofold[Int, Int](t)(_ max _)(identity)
map1put f(value) back in a leafput the two trees back in a branchfold[A, Tree[B]](t)(Branch(_, _))(a => Leaf(f(a)))

Three pieces of syntax that appear here

identity

It is the function that returns its argument as it is: identity(42) is worth 42. It is already in Scala, it does not need to be imported. In maximum1 the value of a leaf is already the result, so g must do nothing: identity is like writing v => v.

Branch(_, _): placeholders

Try replacing _ with x. If the code makes sense as it is, it was a discard. If to make sense you must add x => in front, it was a placeholder.

fold[A, Tree[B]]: types written by hand

Sometimes Scala cannot guess B and it must be written in square brackets. The exercise sheet recommends it, and here it is really needed:

def map1[A, B](t: Tree[A])(f: A => B): Tree[B] =
  fold(t)(Branch(_, _))(a => Leaf(f(a)))
Found:    Tree[Any]
Required: Tree[B]
Senza tipi, Scala deduce un B troppo generico (Tree[Any]). Scrivi fold[A, Tree[B]](t)(…)(…) (verificato: così compila).
