Polymorphism and map

map applies a function to each element of a list and returns the list of results. Writing it just once for all types is called parametric polymorphism: [A, B] are types chosen by whoever calls.

From a map for Ints to one for all

This is parametric polymorphism (generics). The polymorphism of classes, where an overridden method is chosen at runtime, is another thing: it is called dynamic dispatch (week 3).

map step by step

"f: A => B means everything and nothing": where is it decided what f does?

Right: inside the definition of map, f is a hole. It is filled at the moment of the call. Follow the colour of f.

The ready-made functions of the library

From week 3 the lists of the standard library are used, where these functions are methods: they are called with the dot.

MethodDoesExampleResult
map(f)transforms each elementList(1,2,3).map(_ * 2)List(2,4,6)
filter(p)keeps the elements for which p is trueList(1,2,3).filter(_ > 1)List(2,3)
flatMap(f)f gives a list per element, then joins themList(1,2).flatMap(x => List(x, x))List(1,1,2,2)
take(n)the first nList(1,2,3).take(2)List(1,2)
takeWhile(p)the prefix while p holdsList(1,2,5,1).takeWhile(_ < 3)List(1,2)
forall(p)does p hold for all?List(2,4).forall(_ % 2 == 0)true
exists(p)does p hold for at least one?List(1,3).exists(_ % 2 == 0)false
