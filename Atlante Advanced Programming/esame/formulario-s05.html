S5 · State e numeri casuali

Formulario della lezione: la teoria, gli atomi (simboli, tipi, costruttori, funzioni) con cosa chiedono tra parentesi, i pezzi di codice dei tuoi esercizi e in fondo il codice completo animato, con ogni pezzo evidenziato. Torna all'indice del formulario.

Teoria

  • Un generatore con stato nascosto (Random.nextInt) non è puro: due chiamate danno numeri diversi. Soluzione: nextInt: (Int, RNG) restituisce il numero e il nuovo stato. Stesso seme → stessa sequenza (riproducibile, testabile).
  • Mai riusare lo stato vecchio: chiamare due volte nextInt sullo stesso rng dà due volte lo stesso numero.
  • type Rand[+A] = RNG => (A, RNG): "una ricetta per ottenere una A consumando un RNG". I combinatori (unit, map, map2, flatMap, sequence) passano lo stato al posto tuo, in ordine.
  • Il pattern generale: State[S, +A](run: S => (A, S)). get legge lo stato, set(s) lo sostituisce, modify(f) lo trasforma. Si compone anche con for.
  • nonNegativeInt: se n < 0 restituisce -(n+1) e non -n, perché -Int.MinValue va in overflow e resta negativo. double in [0, 1): n / (Int.MaxValue.toDouble + 1) (+1 per escludere l'1).
  • nonNegativeLessThan(bound): usa double (numero in [0,1)) e lo scala: (d * bound).toInt dà un intero da 0 a bound-1. Come un dado con bound facce.
  • stateToLazyList: da un automa a stati a una sequenza infinita (collega S4 e S5).

Pezzi di codice e cosa fanno

RNG · SimpleRNG

trait RNG:
  def nextInt: (Int, RNG)

case class SimpleRNG(seed: Long) extends RNG:
  def nextInt: (Int, RNG) =
    val newSeed = (seed * 0x5DEECE66DL + 0xBL) & 0xFFFFFFFFFFFFL
    val nextRNG = SimpleRNG(newSeed)
    val n = (newSeed >>> 16).toInt
    (n, nextRNG)

Cosa fa. Calcola un nuovo seme (& = AND bit a bit, tiene 48 bit), ne ricava un intero (>>> = shift a destra con zeri) e restituisce la coppia (numero, generatore nuovo).

nonNegativeInt · double · intDouble · doubleInt · ints

def nonNegativeInt(rng: RNG): (Int, RNG) =
  val (num,rand) = rng.nextInt
  (if num<0 then -(num+1) else num, rand)

def double(rng: RNG): (Double, RNG) =
  val (num,rand) = nonNegativeInt(rng)
  (num / (Int.MaxValue.toDouble + 1), rand)

def intDouble(rng: RNG): ((Int, Double), RNG) =
  val (numInt, rand1) = nonNegativeInt(rng)
  val (numDouble, rand2) = double(rand1)
  ((numInt, numDouble), rand2)

def ints(size: Int)(rng: RNG): (List[Int], RNG) =
  if size<=0 then (Nil, rng)
  else
    val(elem1, rand1) = rng.nextInt
    val(elem2, rand2) = ints(size-1)(rand1)
    (elem1 :: elem2, rand2)

Cosa fanno. Ogni funzione prende un rng, ne usa uno nuovo per ogni numero (rand1, rand2) e restituisce l'ultimo stato. doubleInt è intDouble a parti scambiate. ints ricorre: un numero, poi gli altri size-1 a partire dal generatore successivo.

Rand · unit · map · double2 · map2 · sequence · ints2

type Rand[+A] = RNG => (A, RNG)

def unit[A](a: A): Rand[A] = rng => (a, rng)

def map[A,B](s: Rand[A])(f: A => B): Rand[B] =
  rng => {
    val (a, rng2) = s(rng)
    (f(a), rng2) }

lazy val double2: Rand[Double] =
  map(nonNegativeInt)(value => value / (Int.MaxValue.toDouble + 1))

def map2[A, B, C](ra: Rand[A], rb: Rand[B])(f: (A, B) => C): Rand[C] =
  rng => {
    val (a, rng2) = ra(rng)
    val (b, rng3) = rb(rng2)
    (f(a, b), rng3) }

def sequence[A](ras: List[Rand[A]]): Rand[List[A]] = ras match
  case Nil => unit(Nil)
  case h :: t => map2(h,sequence(t))(_ :: _)

def ints2(size: Int): Rand[List[Int]] =
  sequence(List.fill(size)(int))

Cosa fanno. unit: restituisce a senza toccare lo stato. map: trasforma il valore, lo stato passa uguale. map2: esegue ra, passa il suo stato a rb, combina i due valori: lo stato fa la catena rng → rng2 → rng3. sequence: trasforma una lista di ricette in una ricetta di lista. ints2 = size copie di int in sequenza.

flatMap · nonNegativeLessThan

def flatMap[A,B](f: Rand[A])(g: A => Rand[B]): Rand[B] =
  rng => val (a, rng2) = f(rng)
  g(a)(rng2)

def nonNegativeLessThan(bound: Int): Rand[Int] =
  flatMap(double) { dval => unit((dval * bound).toInt) }

Cosa fanno. flatMap: esegue f, usa il valore a per scegliere la ricetta successiva g(a) e la esegue con lo stato aggiornato. nonNegativeLessThan: tira un double in [0,1), lo moltiplica per bound, tronca. Con bound=6: 0…5.

State · flatMap · map · map2 · unit · get · set · modify · sequence

case class State[S, +A](run: S => (A, S)):
  def flatMap[B](f: A => State[S, B]): State[S, B] =
    State { s =>
      val (a, s1) = run(s)
      f(a).run(s1) }

  def map[B](f: A => B): State[S, B] =
    flatMap(a => unit(f(a)))

  def map2[B,C](sb: State[S, B])(f: (A, B) => C): State[S, C] =
    flatMap(a => sb.map(b => f(a, b)))

object State:
  def unit[S, A](a: A): State[S, A] = State { s => (a, s) }
  def get[S]: State[S, S] = State(s => (s, s))
  def set[S](s: S): State[S, Unit] = State(_ => ((), s))

  def modify[S](f: S => S): State[S, Unit] = for
    s <- get
    _ <- set(f(s))
  yield ()

  def sequence[S,A](sas: List[State[S, A]]): State[S, List[A]] = sas match
    case Nil => unit(Nil)
    case h :: t => h.map2(sequence(t))(_ :: _)

  def stateToLazyList[S, A](s: State[S,A])(initial: S): LazyList[A] =
    val (a, next) = s.run(initial)
    cons(a, stateToLazyList(s)(next))

  def lazyInts(rng: RNG): LazyList[Int] =
    stateToLazyList(State(RNG.int))(rng)

Cosa fanno. State è un Rand con lo stato S qualsiasi. flatMap: esegui il primo con s, ottieni (a, s1), scegli il prossimo f(a) ed eseguilo con s1. map e map2 si ricavano da flatMap + unit. get/set/modify leggono e cambiano lo stato. stateToLazyList: esegue lo stato, emette il valore, riparte dal nuovo stato: sequenza infinita di casuali (lazyInts(SimpleRNG(42)).take(10).toList).

Perché chiamare nextInt due volte sullo stesso rng dà lo stesso numero? Scrivi map2 di Rand. Cosa fa flatMap in più di map? Come ottieni un intero tra 0 e 5?
