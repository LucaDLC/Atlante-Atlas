S1 · Funzioni e ricorsione

Formulario della lezione: la teoria, gli atomi (simboli, tipi, costruttori, funzioni) con cosa chiedono tra parentesi, i pezzi di codice dei tuoi esercizi e in fondo il codice completo animato, con ogni pezzo evidenziato. Torna all'indice del formulario.

Teoria

  • Funzione pura: stesso input, stesso output, nessun effetto (niente println, var, eccezioni, I/O). Si può sostituire la chiamata con il suo valore (referential transparency).
  • val non cambia mai. def è una funzione, valutata a ogni chiamata. if e match sono espressioni: restituiscono un valore, quindi niente return.
  • Tipo di una funzione: A => B. Due argomenti: (A, B) => C. Curried: A => B => C, che si legge A => (B => C) (la freccia associa a destra).
  • Ricorsione in coda (tail recursion): la chiamata ricorsiva è l'ultima cosa che la funzione fa. Il compilatore la trasforma in un ciclo, pila costante. @annotation.tailrec dà errore di compilazione se non è davvero in coda.
  • Ricorsione semplice (1 + f(n-1)): dopo il ritorno resta da fare il +1, quindi ogni livello occupa un frame di pila → StackOverflowError su input lunghi.
  • Funzione di ordine superiore (HOF): prende o restituisce funzioni. Polimorfismo: [A] dopo il nome, la funzione vale per ogni tipo.
  • Quando i tipi sono generici l'implementazione è spesso forzata dai tipi (curry, compose): se sei bloccato, segui i tipi.
  • Int in overflow non dà errore: è aritmetica modulo 232.

Pezzi di codice e cosa fanno

fib · Fibonacci in tempo lineare

def fib(n: Int): Int =
  @annotation.tailrec
  def bonacci(n: Int, curr: Int, next: Int): Int =
    if n <= 1 then curr
    else bonacci(n-1, next, next+curr)
  bonacci(n, 0, 1)

Cosa fa. Porta avanti solo gli ultimi due numeri (curr, next). A ogni passo scala n e sposta la finestra. Numerazione dal 1: fib(1)=0, fib(2)=1, fib(3)=1, fib(5)=3. La versione ovvia fib(n-1)+fib(n-2) costa O(φn); questa O(n), pila costante.

isSorted · ordinata senza pattern matching

def isSorted[A](as: Array[A], ordered: (A, A) => Boolean): Boolean =
  @annotation.tailrec
  def Tedsor(i: Int): Boolean =
    if i >= as.length - 1 then true
    else if !ordered(as(i), as(i + 1)) then false
    else Tedsor(i + 1)
  Tedsor(0)

Cosa fa. Controlla solo le coppie adiacenti: basta se ordered è transitiva. Appena una coppia è sbagliata risponde false. Array vuoto o con un elemento: nessuna coppia da violare, quindi true. Il criterio d'ordine è un parametro (HOF).

curry · uncurry · compose

def curry[A, B, C](f: (A, B) => C): A => (B => C) =
  a => b => f(a, b)

def uncurry[A, B, C](f: A => B => C): (A, B) => C =
  (a, b) => f(a)(b)

def compose[A, B, C](f: B => C, g: A => B): A => C =
  a => f(g(a))

def isSortedCurried[A]: Array[A] => ((A, A) => Boolean) => Boolean =
  curry(isSorted[A])

Cosa fanno. curry trasforma una funzione a due argomenti in una che ne prende uno alla volta (applicazione parziale: fisso a, resto con una funzione di b). uncurry è l'inversa: uncurry(curry(f)) == f. compose(f, g) = "f dopo g": prima g, poi f. È associativa e ha identity come neutro.
