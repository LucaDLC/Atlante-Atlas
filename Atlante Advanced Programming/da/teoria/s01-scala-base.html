Ordene du finder i hver fil i kurset: package, object, def, val, if. Plus scala-cli-kommandoerne til at kompilere og køre testene.

Ugens 1-fil, linje for linje

Alt er et udtryk

I Java skiller man sætninger (de gør noget) fra udtryk (de er værd noget). I Scala er næsten alt noget værd, selv en hel blok.

val, var, def: tre måder at give et navn på

SkrevetHvornår den beregnesKan det ændres?I kurset
val x = …med det samme, én gangnejja, altid
def x = …hver gang du skriver xnejja
lazy val x = …ved første brug, derefter husker dennejja (uge 4)
var x = …med det sammeja, med x = …forbudt

Køre koden med scala-cli

Alle kommandoer køres fra ugens mappe og slutter med et punktum, som betyder "denne mappe".

KommandoHvad den gør
scala-cli compile .Kompilerer og basta. Nyttig til at se fejlene.
scala-cli test .Kompilerer og kører testene i Exercises.test.scala.
scala-cli test . -wSom ovenfor, men kører testene igen ved hver gemning. Den anbefalede måde at arbejde på.
scala-cli repl .Åbner REPL'en med din kode indlæst, til at prøve i hånden.
scala-cli run . -M adpro.intro.printAbsKører det angivne @main (-M er nødvendig, hvis der er mere end ét).
scala-cli clean .Sletter de genererede filer. Prøv det, hvis "det virkede før, og nu gør det ikke".

I REPL'en skal funktionerne kaldes med det fulde navn, eller importeres:

scala> import adpro.intro.MyModule.*
scala> abs(-7)
val res0: Int = 7

Typiske fejl

scala> adpro.intro.Exercise.fib(10)
value Exercise is not a member of adpro.intro
Nel package adpro.intro non esiste niente che si chiami Exercise. Controlla il nome esatto dell'object nel file (e se fib sta fuori da ogni object, si chiama adpro.intro.fib(10)). Se hai appena modificato il file, chiudi e riapri scala-cli repl .: il REPL vede il codice compilato all'avvio.

def square(n: Int): Int = return n * n kompilerer uden fejl. Men return står på listen over konstruktioner, der er forbudt i opgaverne og til eksamen: skriv kun n * n. Se Regler og forbud.
