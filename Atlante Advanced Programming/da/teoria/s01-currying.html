Currying og komposition

En funktion med to argumenter kan skrives om som en funktion, der tager ét og returnerer en anden funktion, der venter på det andet. Det kaldes currying. Det bruges til at fastlægge et argument én gang og genbruge resten.

To argumenter sammen, eller ét ad gangen

Sammen

val add2 = (x: Int, y: Int) => x + y
add2(2, 3)   // 5

Type: (Int, Int) => Int. Du skal give begge argumenter med det samme.

Ét ad gangen (curried)

val add = (x: Int) => (y: Int) => x + y
add(2)(3)    // 5

Type: Int => (Int => Int). Hvert argument har sit eget par parenteser.

Det virker også med def'er, der har flere parameterlister: def add(x: Int)(y: Int): Int = x + y, og derefter val incr = add(1) (kontrolleret med Scala 3.8).

At skrive curry: lad typerne bestemme

Øvelse 5. Det ser svært ud, men typerne fortæller dig hvert stykke. Se, hvad du skal producere, og byg det udefra og ind.

def curry[A, B, C](f: (A, B) => C): A => (B => C) = ???

Samme metode for uncurry (øvelse 6), som går den modsatte vej:

curry og uncurry er hinandens inverse: uncurry(curry(f)) opfører sig som f. Det er netop det, testene i øvelse 6 kontrollerer.

isSortedCurried: genbrug i stedet for at skrive om

isSortedCurried(Array(1, 2, 3))(_ <= _)   // true

Det første argument kan konfigurere funktionen for hele projektet, det andet kommer ved kørsel. Og ofte tjener curry/uncurry kun til at få typerne til at passe, når du giver en funktion til en anden, der vil have den i den anden form.

At komponere to funktioner

Øvelse 7: at hægte to funktioner efter hinanden. Uden at bruge bibliotekets compose eller andThen.

def compose[A, B, C](f: B => C, g: A => B): A => C =
  a => f(g(a))
