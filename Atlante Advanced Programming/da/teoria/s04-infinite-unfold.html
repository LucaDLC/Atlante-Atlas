Uendelige lister og unfold

Øvelse 1, 10–13. En uendelig liste defineres med en funktion, der kalder sig selv i halen: takket være cons starter kaldet ikke, før det er nødvendigt. unfold generaliserer idéen: ud fra en startTilstand og en regel "næste værdi og næste tilstand" genererer den hele listen.

ones, from, to, naturals

På almindelige lister ville det være en uendelig løkke. Her ikke: hvert kald bygger én celle og stopper. Den næste celle opstår først, når nogen tvinger halen. naturals.toList derimod terminerer aldrig: den vil have alt.

unfold: den generelle generator (øvelse 11)

def unfold[A, S](z: S)(f: S => Option[(A, S)]): LazyList[A]

Hvorfor unfold?

Den gør det samme som den rekursion, der skrives i hånden, men rekursionen skriver den selv: du beskriver kun ét trin.

I hånden

def map[B](f: A => B): LazyList[B] =
  this match
    case Cons(h, t) =>
      cons(f(h()), t().map(f))
    case Empty => empty

Med unfold

def mapUnfold[B](f: A => B): LazyList[B] =
  unfold(this) {
    case Cons(h, t) =>
      Some((f(h()), t()))
    case Empty => None
  }

To ting ændrer sig: hvor du skrev cons(valore, <ricorsione>), skriver du Some((valore, nuovoStato)); hvor du skrev empty, skriver du None. cons og det rekursive kald sætter unfold ind i sin sidste linje: case Some((a, s)) => cons(a, unfold(s)(f)).

foldRight forbruger en liste og giver en værdi (øvelse 8). unfold starter fra en værdi (tilstanden) og bygger en liste (øvelse 13). I begge tilfælde skriver du ikke rekursionen: på kursets stilskala er det trinnet fra forgivable til enlightened.

Nej. I filen har underviseren skrevet empty, cons, apply (companion) og headOption, tail, foldRight, foldLeft, find (i enum'en). unfold har du skrevet i øvelse 11. Standardbibliotekets LazyList, som kurset ikke bruger, har sin egen: scala.collection.immutable.LazyList.unfold(1)(n => if n > 4 then None else Some((n, n * 2))) → List(1, 2, 4) (kontrolleret).

"naturals.zipWith(_ + _)(naturals) adds each number to itself, so it gives the even numbers 2, 4, 6, …; take(2000000000) costs nothing, because it builds one node at a time.
