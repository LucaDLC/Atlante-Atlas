concat: at udflade en liste af lister

def concat[A](l: List[List[A]]): List[A] =
  foldRight[List[A], List[A]](l, Nil, append)

To valg at forstå:

  • z = Nil: at udflade nul lister giver den tomme liste.
  • f = append: allerede en funktion af typen (List[A], List[A]) => List[A], jeg sender den, som den er.

flatMap: map, derefter udflad

map omdanner hvert element til ét element. flatMap omdanner det til en liste (med nul, ét eller mange elementer) og samler derefter alle listerne.

def flatMap[A, B](l: List[A], f: A => List[B]): List[B] =
  concat(map(l, f))

f giver altid 1 element

flatMap(l, a => List(g(a))) er map.

f giver 0 eller 1 element

flatMap(l, a => if p(a) then List(a) else Nil) er filter (øvelse 15).

f giver mange elementer

Den multiplicerer listen, som i eksemplet ovenfor.

flatMap indeholder både map og filter. I uge 3 bruges den samme operation på Option til at kæde beregninger sammen, der kan fejle: den er hjertet i monader.

zipWith: to lister parallelt

Øvelse 16 lægger to lister sammen position for position. Øvelse 17 generaliserer: ikke kun heltal, ikke kun sum.

zipWith(List(1, 2, 3), List(4, 5, 6, 7), _ + _)   // List(5, 7, 9) — il 7 resta fuori
addPairwise(l, r) == zipWith(l, r, _ + _)          // la vecchia funzione non serve più
