At læse en Scala-signatur

Den første linje i en funktion siger hvad der kommer ind og hvad der kommer ud. Hvis du kan læse den i stykker, fra venstre mod højre, er halvdelen af øvelsen allerede klaret: ofte fortæller typerne dig også, hvordan kroppen skal skrives.

En signatur, taget fra hinanden stykke for stykke

Tag funktionen fra øvelse 4 i uge 1. Den kontrollerer, om et array er sorteret, efter et kriterium, du sender den.

def isSorted[A](as: Array[A], ordered: (A, A) => Boolean): Boolean =

Den samme signatur i Java ville være static <A> boolean isSorted(A[] as, BiPredicate<A,A> ordered). Scala sætter typerne efter navnene, bruger [A] i stedet for <A> og skriver funktionstypen med en pil i stedet for et interface.

Hvornår [A] er nødvendig, og hvornår ikke

Skriv kun [A], når funktionen ikke behøver at vide, hvilken type elementer den har i hånden. Hvis den arbejder med rigtige tal, er typen fast.

Uden [A]

def abs(n: Int): Int =
  if n < 0 then -n else n

abs sammenligner med 0 og skifter fortegn: den har virkelig brug for Int.

Med [A]

def isSorted[A](as: Array[A],
    ordered: (A, A) => Boolean): Boolean

isSorted sammenligner aldrig elementerne selv: den spørger ordered. Den virker med tal, strenge, personer.

Hvem afgør, hvad A bliver? Den, der kalder. Se, hvad der sker i et rigtigt kald:

Typen på en funktion: pilen =>

Til venstre for pilen er der det, der kommer ind, til højre det, der kommer ud. Det er alt.

TypeLæses somEn værdi af den type
Int => Booleantager et Int, giver en Booleanx => x < 0
(Int, Int) => Inttager to Int, giver et Int(x, y) => x + y
(A, A) => Booleantager to A, giver en Boolean(x, y) => x <= y når A = Int
A => Btager et A, giver et B_.toString når A = Int og B = String
() => Atager intet, giver et A() => 42 (uge 4)

f: A => B siger ikke, hvad f gør. Den siger kun, hvilken form den har: et A kommer ind, et B kommer ud. Hvad den virkelig gør, afgøres af den, der sender funktionen med ved kaldet.

Pile inde i hinanden

I øvelse 5 optræder denne signatur, der ligner en russisk dukke:

def isSortedCurried[A]: Array[A] => ((A, A) => Boolean) => Boolean

Flere parameterlister

En funktion kan have flere par parenteser. I kaldet skriver du lige så mange, i samme rækkefølge.

Hvis definitionen har to lister, og du kalder med kun én, map(albero, f), kompilerer det ikke. Tæl parenteserne i definitionen.

Metoder inde i en enum: hvor kommer A fra?

Fra uge 3 er nogle funktioner skrevet inde i typen, som metoder. Så er A ikke blandt metodens firkantede parenteser: det kommer fra enum'en.
