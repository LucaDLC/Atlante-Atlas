Pattern matching

x match spørger "hvilken form har x?". Hvert case beskriver en mulig form. Scala prøver case'ene oppefra og vælger det første, der passer, og undervejs giver den et navn til de dele, du har brug for.

At læse et match

Fra cellen selv. Cons(head: A, tail: List[A]) har to felter, i den rækkefølge. Mønsteret Cons(h, _) stiller dem op med de navne, du vælger: det første kaldes h, det andet smider du væk. Du kunne skrive Cons(primo, resto), og det ville være det samme.

Et match udført tilfælde for tilfælde

Øvelse 1 i uge 2: hvad er dette udtryk værd? Man svarer uden at køre, ved at prøve tilfældene i rækkefølge.

List(1, 2, 3, 4, 5) match
  case Cons(x, Cons(2, Cons(4, _))) => x
  case Nil => 42
  case Cons(x, Cons(y, Cons(3, Cons(4, _)))) => x + y
  case Cons(h, t) => h
  case _ => 101

Når dette match kompileres med -Werror (kursets project.scala), markerer Scala det sidste tilfælde: Unreachable case except for null. Enhver liste er Nil eller Cons, og case Cons(h, t) tager dem allerede alle: case _ => 101 kan aldrig slå til.

Hvad der kan skrives i et mønster

MønsterPasser medNavne det opretter

Cons(h, t)enhver celleh hoved, t hale
Cons(_, Nil)en liste med ét enkelt elementingen
Cons(2, t)en liste, der begynder med 2t

I mønstre er et navn med småt et nyt navn, som bliver udfyldt. Et navn med stort begyndelsesbogstav er noget, der allerede skal findes (en konstruktør som Nil eller en konstant).

Vagter: case … if

Efter mønsteret kan du tilføje en betingelse. Tilfældet gælder kun, hvis mønsteret passer og betingelsen er sand.

Match på to lister sammen

For at gennemløbe to lister parallelt sætter du de to lister i et par og laver match på parret (øvelse 16).

Typiske fejl

Alle taget fra rigtige forsøg på øvelserne, med den meddelelse Scala 3.8 giver.

def size[A](t: Tree[A]): Int = match
  case Leaf(_) => 1
expression expected but match found
Manca il soggetto prima di match: scrivi = t match.
case Const(h, t) => h * product(t)
no pattern match extractor named Const was found
Il costruttore si chiama Cons, senza la t. (Seguono altri errori a cascata come value * is not a member of Any: sparisce tutto correggendo il nome.)
def drop[A](l: List[A], n: Int): List[A] = l match
  case n < 0 => l
no pattern match extractor named < was found
Un pattern descrive una forma, non una condizione. Per controllare n usa un if prima del match, o una guardia: case _ if n <= 0 => l.
case Some(X) => X
Not found: X
Maiuscolo = Scala cerca una X che esiste già. Per un nome nuovo usa il minuscolo: case Some(x) => x.
def head[A](l: List[A]): A = l match
  case Cons(h, _) => h
match may not be exhaustive.
