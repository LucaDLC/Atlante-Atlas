Eksempler: map, distribute og map2 i Scala

Koden fra siden om functor, med map på List og Option, identitetsloven, distribute og map2. Kontrolleret med Scala 3.8.4 og kursets indstillinger.

Hele filen

Kør den med scala-cli run Functor.scala. distribute er skrevet for lister, map2 for Option: det er de konkrete versioner af begrebet.

Outputtet

Husk

A functor is a type constructor with a map operation that preserves the structure: mapping the identity changes nothing.
En map på kursets containere har altid samme form: hvis du har to containere at kombinere, er map ikke nok, du har brug for map2 (og dens form med flatMap).
