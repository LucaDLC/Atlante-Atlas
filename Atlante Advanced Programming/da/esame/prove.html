Spørgsmål i eksamensstil

Skrevet til atlasset efter modellen af kursets opgaver: de er ikke officielle eksamener. Hver løsning er kompileret med Scala 3.8.4.

1 · Tælle med et fold

Implementér uden eksplicit rekursion en funktion, der tæller elementerne i en liste, der opfylder p.

def count[A](l: List[A])(p: A => Boolean): Int = ???
Vis løsningen
def count[A](l: List[A])(p: A => Boolean): Int =
  l.foldLeft(0)((acc, a) => if p(a) then acc + 1 else acc)

z = 0 (tom liste: nul elementer). Trinnet lægger kun 1 til, hvis p(a). count(List(1,2,3,4,5))(_ % 2 == 1) giver 3.

2 · Det sidste element, måske

Implementér lastOption med et fold, uden pattern matching.

def lastOption[A](l: List[A]): Option[A] = ???
Vis løsningen
def lastOption[A](l: List[A]): Option[A] =
  l.foldLeft[Option[A]](None)((_, a) => Some(a))

Hvert trin smider akkumulatoren væk og beholder det aktuelle element: til sidst er det sidste tilbage. Typen [Option[A]] er nødvendig, fordi None alene ville have typen None.type. Resultater: Some(9) for List(7, 8, 9), None for den tomme liste.

3 · Filtrér og transformér samtidig

Givet en funktion, der kan fejle, behold kun de vellykkede resultater.

def filterMap[A, B](l: List[A])(f: A => Option[B]): List[B] = ???
// filterMap(List("1", "x", "3"))(_.toIntOption) == List(1, 3)
Vis løsningen
def filterMap[A, B](l: List[A])(f: A => Option[B]): List[B] =
  l.foldRight(List.empty[B])((a, acc) => f(a).map(_ :: acc).getOrElse(acc))

foldRight bevarer rækkefølgen. Hvis f(a) er Some(b), sætter map den foran resten; hvis det er None, returnerer getOrElse resten uændret.

4 · Dybden af et træ

Brug fold på træerne fra uge 3 og beregn dybden: et blad har dybde 0, en gren 1 + dybden af det dybeste barn.

Vis løsningen
def depth[A](t: Tree[A]): Int =
  fold[A, Int](t)((l, r) => 1 + (l max r))(_ => 0)

g for bladene: 0, uanset værdien. f for grenene: 1 plus det største af de to. depth(Branch(Branch(Leaf(1), Leaf(5)), Leaf(3))) giver 2.

5 · forAll på Option uden pattern matching

Implementér forAll (sand hvis Option er tom, eller hvis værdien opfylder p) med kun map og getOrElse.

Vis løsningen
def forAll[A](o: Option[A])(p: A => Boolean): Boolean =
  o.map(p).getOrElse(true)

map(p) omdanner Some(a) til Some(p(a)). På None er "for alle elementer" tomt sandt: standard true.

6 · Hvad udskriver den?

def twice(x: => Int): Int = x + x
def twiceLazy(x: => Int): Int =
  lazy val y = x
  y + y

println(twice({ println("hi"); 1 }))
println(twiceLazy({ println("hi"); 1 }))
Vis løsningen
hi
hi
2
hi
2

twice: x er by-name og optræder to gange, så blokken køres to gange. twiceLazy: lazy val'en beregner den én gang og husker den derefter.

7 · En uendelig liste med unfold

Implementér iterate: LazyList'en a, f(a), f(f(a)), …, med unfold.

Vis løsningen
def iterate[A](a: A)(f: A => A): LazyList[A] =
  unfold(a)(x => Some((x, f(x))))

Tilstanden er den aktuelle værdi: jeg udsender den, og den nye tilstand er f(x). Aldrig None: listen er uendelig. iterate(1)(_ * 3).take(4).toList giver List(1, 3, 9, 27).

8 · Varians

Med class Cat extends Animal: kompilerer val o: Option[Animal] = Some(Cat())? Og val a: Array[Animal] = cats, hvis cats: Array[Cat]? Hvorfor?

Vis løsningen

Den første ja: Option[+A] er kovariant, så Option[Cat] <: Option[Animal]. Den anden nej: arrays er mutable og i Scala invariante (Found: Array[Cat], Required: Array[Animal]). Hvis de var det, kunne du skrive en Dog ind i et array af Cat.

9 · Åbent spørgsmål, på engelsk

Why is foldLeft on a strict List tail-recursive while foldRight is not? When would you still prefer foldRight?

Vis et modelsvar

"In foldLeft the combining function is applied before the recursive call, so the call is the last thing the function does and the compiler can turn it into a loop with constant stack space. foldRight must first compute the result for the tail and only then apply f to the head, so each element leaves a pending call on the stack. I would still use foldRight when the result must preserve the order of the list, for example when building a list with Cons, and on lazy lists, where f may return without forcing the rest and the fold can stop early."
