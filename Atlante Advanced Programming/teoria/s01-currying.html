Currying e composizione

Una funzione a due argomenti si può riscrivere come una funzione che ne prende uno e restituisce un'altra funzione che aspetta il secondo. Si chiama currying. Serve a fissare un argomento una volta e riusare il resto.

Due argomenti insieme, o uno alla volta

Insieme

val add2 = (x: Int, y: Int) => x + y
add2(2, 3)   // 5

Tipo: (Int, Int) => Int. Devi dare tutti e due gli argomenti subito.

Uno alla volta (curried)

val add = (x: Int) => (y: Int) => x + y
add(2)(3)    // 5

Tipo: Int => (Int => Int). Ogni argomento ha la sua coppia di parentesi.

Funziona anche con i def che hanno più liste di parametri: def add(x: Int)(y: Int): Int = x + y, e poi val incr = add(1) (verificato con Scala 3.8).

def curry[A, B, C](f: (A, B) => C): A => (B => C) = ???

Stesso metodo per uncurry (esercizio 6), che fa il viaggio inverso:

curry e uncurry sono una l'inversa dell'altra: uncurry(curry(f)) si comporta come f. È esattamente quello che controllano i test dell'esercizio 6.

isSortedCurried: riusare invece di riscrivere

isSortedCurried(Array(1, 2, 3))(_ <= _)   // true

Il primo argomento può configurare la funzione per tutto il progetto, il secondo arriva a runtime. E spesso curry/uncurry servono solo a far combaciare i tipi quando passi una funzione a un'altra che la vuole nell'altra forma.

Comporre due funzioni

Esercizio 7: attaccare due funzioni in fila. Senza usare compose o andThen della libreria.

def compose[A, B, C](f: B => C, g: A => B): A => C =
  a => f(g(a))
