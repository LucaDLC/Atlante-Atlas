Trait e mixin

Un trait è un pezzo di classe che puoi aggiungere a più classi: può avere metodi già scritti, metodi da completare e campi. Una classe può "mescolarne" quanti vuole. Nell'esercizio 1 della settimana 3 lo usi per aggiungere < a una classe Java.

Da Java a Scala

In Java una classe ha un solo genitore, ma può implementare più interfacce. Un trait è come un'interfaccia Java che può contenere anche codice e campi.

L'esempio della lezione: la rana

trait Audible:
  def makeNoise(): String
class Frog extends Audible
class Frog needs to be abstract, since def makeNoise(): String in trait Audible is not defined
Hai mescolato un trait con un metodo astratto e non l'hai scritto. Aggiungi def makeNoise(): String = … dentro Frog.

Esercizio 1, settimana 3: OrderedPoint

Obiettivo: poter scrivere p < q tra due java.awt.Point, una classe Java che non puoi modificare. La libreria Scala ha già il trait Ordered[T]: se scrivi il metodo compare, ti regala <, >, <=, >=.

trait OrderedPoint extends scala.math.Ordered[java.awt.Point]:
  override def compare(that: java.awt.Point): Int =
    if this.x < that.x then -1 else 1
value x is not a member of OrderedPoint
Senza this: java.awt.Point => il trait non sa di essere dentro un Point, quindi this.x non esiste.

Funziona solo se crei tu l'oggetto, perché devi scrivere with OrderedPoint. Un Point che ti arriva già fatto da una libreria non ha il trait. Il foglio esercizi annuncia che più avanti si vedranno le type class, che risolvono proprio questo.

Due trait con lo stesso metodo: chi vince?

Se due trait ridefiniscono lo stesso metodo, Scala li mette in fila: vince quello più a destra, e super passa al successivo nella fila.

trait Base:
  def saluta: String = "Base"
trait A extends Base:
  override def saluta: String = "A>" + super.saluta
trait B extends Base:
  override def saluta: String = "B>" + super.saluta

class X extends A, B     // X().saluta == "B>A>Base"
class Y extends B, A     // Y().saluta == "A>B>Base"

Risultati verificati compilando. Nel corso basta sapere la regola "vince il più a destra".
