Classi e dispatch dinamico

Due argomenti di programmazione a oggetti con cui si apre la settimana 3: il costruttore primario (una classe Java di 15 righe diventa una riga) e il dispatch dinamico (quale metodo viene chiamato davvero quando una sottoclasse lo ridefinisce).

Il costruttore primario

In Scala i parametri del costruttore si scrivono subito dopo il nome della classe. Tutto il resto del corpo della classe viene eseguito quando l'oggetto viene creato.

Scala

class Person(val name: String, val age: Int):
  println("Just constructed a person")
  def description =
    s"$name is $age years old"

Lo stesso in Java

class Person {
  private String name;
  private int age;
  public String name() { return name; }
  public int age() { return age; }
  public Person(String name, int age) {
    this.name = name;
    this.age = age;
    System.out.println("Just constructed a person");
  }
  public String description() {
    return name + " is " + age + " years old";
  }
}

I costruttori primari si usano con le case class e con i case degli enum: Cons(head: A, tail: List[A]) è proprio un costruttore primario.

Sondaggio: dispatch dinamico in Java

class Printable            { void hello() { print("printable "); } }
class Triangle extends Printable { void hello() { print("triangle "); } }
class Square   extends Printable { void hello() { print("square "); } }

Square x    = new Square();
Printable y = new Triangle();

x.hello();
((Printable) x).hello();
y.hello();
((Printable) y).hello();

Come in Java, Python e JavaScript, tutti i metodi d'istanza sono virtuali: vengono scelti in base all'oggetto vero. (In C# e C++ invece no, se non lo dichiari.)

Cosa stampa? Risposta: square square triangle triangle. Il metodo viene scelto in base alla classe vera dell'oggetto, decisa con new, non in base al tipo della variabile o al cast. Il cast (Printable) x cambia solo cosa il compilatore ti lascia chiamare, non l'oggetto.
