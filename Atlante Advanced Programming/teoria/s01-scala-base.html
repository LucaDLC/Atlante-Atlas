Scala in dieci minuti

Le parole che trovi in ogni file del corso: package, object, def, val, if. Più i comandi di scala-cli per compilare e lanciare i test.

Il file della settimana 1, riga per riga

Questo è l'inizio di 01-intro/Exercises.scala. Contiene quasi tutta la sintassi di base.

Tutto è un'espressione

In Java separi istruzioni (fanno qualcosa) ed espressioni (valgono qualcosa). In Scala quasi tutto vale qualcosa, anche un blocco intero.

val, var, def: tre modi di dare un nome

Lanciare il codice con scala-cli

Tutti i comandi si lanciano dalla cartella della settimana e finiscono con un punto, che vuol dire "questa cartella".

ComandoCosa fa
scala-cli compile .Compila e basta. Utile per vedere gli errori.
scala-cli test .Compila e lancia i test di Exercises.test.scala.
scala-cli test . -wCome sopra, ma rilancia i test a ogni salvataggio. Il modo consigliato di lavorare.
scala-cli repl .Apre il REPL con il tuo codice caricato, per provare a mano.
scala-cli run . -M adpro.intro.printAbsEsegue il @main indicato (serve -M se ce n'è più di uno).
scala-cli clean .Cancella i file generati. Prova questo se "prima funzionava e ora no".

Nel REPL le funzioni vanno chiamate con il nome completo, oppure importate:

scala> import adpro.intro.MyModule.*
scala> abs(-7)
val res0: Int = 7

Errori tipici

scala> adpro.intro.Exercise.fib(10)
value Exercise is not a member of adpro.intro
Nel package adpro.intro non esiste niente che si chiami Exercise. Controlla il nome esatto dell'object nel file (e se fib sta fuori da ogni object, si chiama adpro.intro.fib(10)). Se hai appena modificato il file, chiudi e riapri scala-cli repl .: il REPL vede il codice compilato all'avvio.

def square(n: Int): Int = return n * n compila senza errori. Però return è nella lista dei costrutti vietati negli esercizi e all'esame: scrivi solo n * n. Vedi Regole e divieti.
