Pattern matching

x match chiede "che forma ha x?". Ogni case descrive una forma possibile. Scala prova i case dall'alto e sceglie il primo che combacia, e intanto dà un nome ai pezzi che ti servono.

Leggere un match

Dalla cella stessa. Cons(head: A, tail: List[A]) ha due campi, in quell'ordine. Il pattern Cons(h, _) li mette in fila con i nomi che scegli tu: il primo si chiama h, il secondo lo butti. Potresti scrivere Cons(primo, resto) e sarebbe uguale.

Un match eseguito caso per caso

Esercizio 1 della settimana 2: quanto vale questa espressione? Si risponde senza eseguire, provando i casi in ordine.

List(1, 2, 3, 4, 5) match
  case Cons(x, Cons(2, Cons(4, _))) => x
  case Nil => 42
  case Cons(x, Cons(y, Cons(3, Cons(4, _)))) => x + y
  case Cons(h, t) => h
  case _ => 101

Compilando questo match con -Werror (il project.scala del corso) Scala segnala l'ultimo caso: Unreachable case except for null. Ogni lista è Nil o Cons, e case Cons(h, t) le prende già tutte: case _ => 101 non può mai scattare.

Nei pattern un nome minuscolo è un nome nuovo, che si riempie. Un nome Maiuscolo è una cosa che deve già esistere (un costruttore come Nil o una costante).

Guardie: case … if

Dopo il pattern puoi aggiungere una condizione. Il caso vale solo se il pattern combacia e la condizione è vera.

Match su due liste insieme

Per scorrere due liste in parallelo metti le due liste in una coppia e fai il match sulla coppia (esercizio 16).

Errori tipici

Tutti presi da tentativi veri degli esercizi, con il messaggio che dà Scala 3.8.

def size[A](t: Tree[A]): Int = match
  case Leaf(_) => 1
expression expected but match found
Manca il soggetto prima di match: scrivi = t match.
case Const(h, t) => h * product(t)
no pattern match extractor named Const was found
Il costruttore si chiama Cons, senza la t. (Seguono altri errori a cascata come value * is not a member of Any: sparisce tutto correggendo il nome.)
def drop[A](l: List[A], n: Int): List[A] = l match
  case n < 0 => l
no pattern match extractor named < was found
Un pattern descrive una forma, non una condizione. Per controllare n usa un if prima del match, o una guardia: case _ if n <= 0 => l.
case Some(X) => X
Not found: X
Maiuscolo = Scala cerca una X che esiste già. Per un nome nuovo usa il minuscolo: case Some(x) => x.
def head[A](l: List[A]): A = l match
  case Cons(h, _) => h
match may not be exhaustive.
