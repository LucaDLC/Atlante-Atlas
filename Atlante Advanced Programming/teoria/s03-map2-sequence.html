map2, sequence, traverse

Esercizi 9–11. Tre modi di combinare più Option: map2 ne unisce due, sequence trasforma una lista di Option in un Option di lista, traverse fa map e sequence insieme. In tutti: se anche un solo pezzo manca, il risultato è None.

map2: combinare due Option

1) map2 "solleva" una funzione a due argomenti nel mondo degli Option. 2) È un sequenziatore: esegue due calcoli che possono fallire e combina i risultati solo se entrambi riescono.

Il simbolo ::

Dalla settimana 3 si usano le liste della libreria standard. :: è il loro Cons, scritto in mezzo: x :: resto è la lista con x davanti a resto.

sequence: da List[Option[A]] a Option[List[A]]

Esempio del testo: per ogni impiegato hai chiesto lo stipendio al database. Ogni risposta è un Option (None se la connessione è caduta). Vuoi tutti gli stipendi, oppure sapere che qualcosa è andato storto.

Il testo osserva che sequence non dovrebbe essere un metodo di List (legherebbe le liste agli Option) e non può essere un metodo di Option (il suo argomento è una lista). Quindi va come funzione a sé, nel file o nel companion object.

traverse: map e sequence in un passaggio

traverse(List(1, 2, 3))(x => if x > 0 then Some(x * 10) else None)    // Some(List(10, 20, 30))
traverse(List(1, -2, 3))(x => if x > 0 then Some(x * 10) else None)   // None

Perché non sequence(as.map(f))? Dà lo stesso risultato, ma map non sa niente di Option: applica f a tutta la lista e costruisce una lista intermedia, anche se il primo elemento fallisce. traverse fa tutto in un'unica passata.
