filter, flatMap, zipWith

Esercizi 12–18: le funzioni che userai più spesso, costruite con fold e con quelle già scritte. Il foglio esercizi insiste su una: flatMap, che "sarà la chiave per il resto del corso".

concat: appiattire una lista di liste

def concat[A](l: List[List[A]]): List[A] =
  foldRight[List[A], List[A]](l, Nil, append)

Due scelte da capire:

  • z = Nil: appiattire zero liste dà la lista vuota.
  • f = append: già una funzione di tipo (List[A], List[A]) => List[A], la passo così com'è.

filter con foldRight

flatMap: map, poi appiattisci

map trasforma ogni elemento in un elemento. flatMap lo trasforma in una lista (con zero, uno o molti elementi) e poi unisce tutte le liste.

def flatMap[A, B](l: List[A], f: A => List[B]): List[B] =
  concat(map(l, f))

f dà sempre 1 elemento

flatMap(l, a => List(g(a))) è map.

f dà 0 o 1 elementi

flatMap(l, a => if p(a) then List(a) else Nil) è filter (esercizio 15).

f dà molti elementi

Moltiplica la lista, come nell'esempio sopra.

flatMap contiene sia map sia filter. Nella settimana 3 la stessa operazione, su Option, serve a concatenare calcoli che possono fallire: è il cuore delle monadi.

zipWith: due liste in parallelo

Esercizio 16 somma due liste posizione per posizione. Esercizio 17 generalizza: non solo interi, non solo somma.

zipWith(List(1, 2, 3), List(4, 5, 6, 7), _ + _)   // List(5, 7, 9) — il 7 resta fuori
addPairwise(l, r) == zipWith(l, r, _ + _)          // la vecchia funzione non serve più
