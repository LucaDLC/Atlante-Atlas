Leggere una firma Scala

La prima riga di una funzione dice cosa entra e cosa esce. Se la sai leggere a pezzi, da sinistra a destra, metà dell'esercizio è già fatta: spesso i tipi ti dicono anche come scrivere il corpo.

Una firma, smontata pezzo per pezzo

Prendiamo la funzione dell'esercizio 4 della settimana 1. Controlla se un array è ordinato, secondo un criterio che le passi tu.

def isSorted[A](as: Array[A], ordered: (A, A) => Boolean): Boolean =

La stessa firma in Java sarebbe static <A> boolean isSorted(A[] as, BiPredicate<A,A> ordered). Scala mette i tipi dopo i nomi, usa [A] al posto di <A> e scrive il tipo della funzione con una freccia invece di un'interfaccia.

Quando serve [A] e quando no

Metti [A] solo quando la funzione non ha bisogno di sapere che tipo di elementi ha in mano. Se lavora con numeri veri, il tipo è fisso.

Senza [A]

def abs(n: Int): Int =
  if n < 0 then -n else n

abs confronta con 0 e cambia segno: servono proprio degli Int.

Con [A]

def isSorted[A](as: Array[A],
    ordered: (A, A) => Boolean): Boolean

isSorted non confronta mai gli elementi da sola: chiede a ordered. Funziona con numeri, stringhe, persone.

Chi decide cosa diventa A? Chi chiama. Guarda cosa succede a una chiamata vera:

Il tipo di una funzione: la freccia =>

A sinistra della freccia c'è cosa entra, a destra cosa esce. Tutto qui.

TipoSi leggeUn valore di quel tipo
Int => Booleanprende un Int, dà un Booleanx => x < 0
(Int, Int) => Intprende due Int, dà un Int(x, y) => x + y
(A, A) => Booleanprende due A, dà un Boolean(x, y) => x <= y quando A = Int
A => Bprende un A, dà un B_.toString quando A = Int e B = String
() => Anon prende niente, dà un A() => 42 (settimana 4)

f: A => B non dice cosa fa f. Dice solo che forma ha: entra un A, esce un B. Cosa fa davvero lo decide chi passa la funzione al momento della chiamata.

Frecce una dentro l'altra

Nell'esercizio 5 compare questa firma, che sembra una matrioska:

def isSortedCurried[A]: Array[A] => ((A, A) => Boolean) => Boolean

Più liste di parametri

Una funzione può avere più coppie di parentesi. Nella chiamata ne scrivi lo stesso numero, nello stesso ordine.

Se la definizione ha due liste e tu chiami con una sola, map(albero, f), non compila. Conta le coppie di parentesi nella definizione.
