Funzioni come valori

In Scala una funzione è un valore come 42 o "ciao": la metti in una val, la passi a un'altra funzione, la restituisci. Una funzione che riceve o restituisce funzioni si chiama di ordine superiore (higher-order function, HOF).

Scrivere un valore, scrivere una funzione

Per i dati hai i letterali: scrivi il valore direttamente nel codice.

val l = List(1, -2, 3)        // una lista
val a = Array(-1, 2, -3)      // un array
val z = (42, false)           // una coppia

Anche per le funzioni esiste un letterale: la funzione anonima (o lambda). Non ha un nome, lo prende solo se la metti in una val.

Passare una funzione a un'altra

filter è un metodo delle liste che riceve una funzione "sì/no" e tiene solo gli elementi per cui la risposta è sì. Chi chiama la tua funzione è filter, una volta per elemento.

x non esiste prima. È il nome del parametro della funzione che hai scritto. Il valore glielo dà chi la chiama, qui filter. È la stessa cosa che succede quando chiami abs(-3): dentro abs, n vale -3.

p contro p(h)

Quando una funzione riceve un'altra funzione come parametro, dentro il corpo puoi fare due cose diverse con quel nome. È la tua soluzione di dropWhile (settimana 2).

Tre modi di scrivere la stessa funzione

Scala permette di accorciare le funzioni anonime quando capisce da solo i tipi.

List(1, 2, 3).map(_ * _)
Wrong number of parameters, expected: 1
_ * _ è una funzione a due parametri, ma map ne vuole una a uno. Per "moltiplica x per se stesso" serve il nome: map(x => x * x).
val negative = x => x < 0
Missing parameter type

I could not infer the type of the parameter x
Qui non c'è nessuna lista da cui dedurre il tipo di x. Scrivilo: (x: Int) => x < 0.
