Polimorfismo e map

map applica una funzione a ogni elemento di una lista e restituisce la lista dei risultati. Scriverla una volta sola per tutti i tipi si chiama polimorfismo parametrico: [A, B] sono tipi che sceglie chi chiama.

Da una map per gli Int a una per tutti

Questo è polimorfismo parametrico (generics). Il polimorfismo delle classi, dove un metodo sovrascritto viene scelto a runtime, è un'altra cosa: si chiama dispatch dinamico (settimana 3).

map passo per passo

"f: A => B vuol dire tutto e niente": dove si decide cosa fa f?

Le funzioni pronte della libreria

Dalla settimana 3 si usano le liste della libreria standard, dove queste funzioni sono metodi: si chiamano con il punto.

MetodoFaEsempioRisultato
map(f)trasforma ogni elementoList(1,2,3).map(_ * 2)List(2,4,6)
filter(p)tiene gli elementi con p veroList(1,2,3).filter(_ > 1)List(2,3)
flatMap(f)f dà una lista per elemento, poi le unisceList(1,2).flatMap(x => List(x, x))List(1,1,2,2)
take(n)i primi nList(1,2,3).take(2)List(1,2)
takeWhile(p)il prefisso finché p valeList(1,2,5,1).takeWhile(_ < 3)List(1,2)
forall(p)p vale per tutti?List(2,4).forall(_ % 2 == 0)true
exists(p)p vale per almeno uno?List(1,3).exists(_ % 2 == 0)false

Negli esercizi della settimana 2 si usa la lista del corso, non quella della libreria. Il testo avverte: non cercare le funzioni nella documentazione online, sono diverse. Puoi usare solo quelle in cima a Exercises.scala e quelle scritte negli esercizi precedenti.
