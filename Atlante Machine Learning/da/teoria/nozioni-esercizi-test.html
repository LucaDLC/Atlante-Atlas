Håndøvelser til in-class-testen

Den første in-class-test er mandag 28. september, i de første 30–45 minutter af lektion 6: papir og blyant, om materialet fra uge 1–5 (går det dårligt, er der resit i uge 41). Her er 14 øvelser af samme type som Grasple- og in-class-aktiviteterne, hver med løsningen trin for trin. Prøv først selv, og åbn derefter løsningen. Alle resultaterne er kontrolleret med NumPy.

Vektorer (uge 1–2)

1. u = (1, 2, 2), w = (3, 0, 4). Beregn ‖u‖, ‖w‖ og afstanden d(u, w).

Løsning

‖u‖ = √(1 + 4 + 4) = √9 = 3. ‖w‖ = √(9 + 0 + 16) = √25 = 5.

u − w = (−2, 2, −2) ⇒ d = √(4 + 4 + 4) = √12 ≈ 3.46. Først kvadraterne, derefter summen, derefter kvadratroden (normer).

2. Samme vektorer: indre produkt og vinkel.

Løsning

u · w = 1·3 + 2·0 + 2·4 = 11. cos θ = 11 / (3 · 5) = 11/15 ≈ 0.733 ⇒ θ ≈ 42.8°.

3. Projicer w = (2, 3) på retningen af u = (1, 1).

Løsning

(u · w / u · u) · u = (5 / 2) · (1, 1) = (2.5, 2.5). Kontrol: w − projektion = (−0.5, 0.5), vinkelret på u (indre produkt 0).

4. Modellen f(x) = 2x + 1 på dataene (1, 3), (2, 4), (3, 8). Beregn loss ved mindste kvadrater L = (1/N) Σ (yᵢ − f(xᵢ))².

Løsning

Forudsigelser: 3, 5, 7. Fejl: 3 − 3 = 0, 4 − 5 = −1, 8 − 7 = 1. Kvadrater: 0, 1, 1. L = 2/3 ≈ 0.667. N = antallet af punkter (3), ikke af modeller (loss).

Matricer og systemer (uge 3)

5. [[1, 2], [0, −1], [3, 1]] · (2, 1) = ? Først dimensionerne.

Løsning

(3 × 2) · (2) → 3 tal, ét pr. række (dimensioner). Række 1: 1·2 + 2·1 = 4. Række 2: 0·2 + (−1)·1 = −1. Række 3: 3·2 + 1·1 = 7. Resultat (4, −1, 7).

6. A = [[1, 2], [3, 4]], B = [[0, 1], [1, 0]]. Beregn AB og BA.

Løsning

AB = [[1·0 + 2·1, 1·1 + 2·0], [3·0 + 4·1, 3·1 + 4·0]] = [[2, 1], [4, 3]] (bytter søjlerne i A).

BA = [[3, 4], [1, 2]] (bytter rækkerne i A). AB ≠ BA: rækkefølgen betyder noget.

7. A = [[2, 1], [5, 3]]. Determinant, invers og løsningen af Ax = (1, 2).

Løsning

det = 2·3 − 1·5 = 1. For en 2 × 2 [[a, b], [c, d]]: A⁻¹ = (1/det) [[d, −b], [−c, a]] = [[3, −1], [−5, 2]].

x = A⁻¹(1, 2) = (3·1 − 1·2, −5·1 + 2·2) = (1, −1). Kontrol: 2·1 + 1·(−1) = 1 ✓, 5·1 + 3·(−1) = 2 ✓.

8. [[1, 2], [2, 4]] x = b. Hvor mange løsninger med b = (3, 6)? Og med b = (3, 5)?

Løsning

det = 4 − 4 = 0: den anden række er dobbelt så stor som den første (rang 1).

b = (3, 6): den anden ligning er dobbelt så stor som den første ⇒ kun én ligning, x₁ + 2x₂ = 3 ⇒ uendeligt mange løsninger. b = (3, 5): 2x₁ + 4x₂ skulle være lig med både 6 og 5 samtidig ⇒ ingen løsning (systemer).

9. Find linjen y = w₀ + w₁x gennem (1, 1) og (3, 5), og skriv systemet op.

Løsning

w₀ + 1·w₁ = 1 og w₀ + 3·w₁ = 5. Ved at trække fra: 2w₁ = 4 ⇒ w₁ = 2; derefter w₀ = 1 − 2 = −1. Linjen y = −1 + 2x. I matrixform: [[1, 1], [1, 3]] · [w₀, w₁] = [1, 5] (isolere w).

10. Er (1, 2, 3) og (2, 4, 6) uafhængige? Og (1, 0, 1), (0, 1, 1), (1, 1, 0)?

Løsning

(2, 4, 6) = 2·(1, 2, 3): afhængige. For de tre vektorer: matricen med dem som søjler har determinant −2 ≠ 0 ⇒ uafhængige (og de er en basis for ℝ³) (baser).

Transformationer og mindste kvadrater (uge 4–5)

11. R = rotation på 90°, [[0, −1], [1, 0]]; S = [[2, 0], [0, 1]]. Beregn R · (2, 1), derefter SR · (1, 0) og RS · (1, 0).

Løsning

R · (2, 1) = (0·2 − 1·1, 1·2 + 0·1) = (−1, 2).

SR(1, 0): først R → (0, 1), derefter S → (0, 1). RS(1, 0): først S → (2, 0), derefter R → (0, 2). Den matrix, der står længst til højre, anvendes først; rækkefølgen ændrer resultatet (transformationer).

12. Flyt punktet (1, 2) med (3, −1) ved hjælp af homogene koordinater.

Løsning

[[1, 0, 3], [0, 1, −1], [0, 0, 1]] · [1, 2, 1] = [1 + 3, 2 − 1, 1] = (4, 1). Den 1, der er tilføjet nederst, ganger translationen (homogene).

13. Polynomiet af grad 2, der går gennem (−1, 2), (0, 1), (1, 2).

Løsning

y = w₀ + w₁x + w₂x². Fra (0, 1): w₀ = 1. Fra (1, 2): 1 + w₁ + w₂ = 2. Fra (−1, 2): 1 − w₁ + w₂ = 2. Lægger man de to sidste sammen: 2 + 2w₂ = 4 ⇒ w₂ = 1, altså w₁ = 0. y = 1 + x².

14. Linjen ved mindste kvadrater for (0, 1), (1, 1), (2, 3), med w = (AᵀA)⁻¹Aᵀy.

Løsning

A = [[1, 0], [1, 1], [1, 2]], y = (1, 1, 3). AᵀA = [[3, 3], [3, 5]] (øverst: hvor mange punkter; derefter Σx; nederst Σx²). Aᵀy = (Σy, Σxy) = (5, 7).

det(AᵀA) = 15 − 9 = 6; (AᵀA)⁻¹ = (1/6) [[5, −3], [−3, 3]]. w = (1/6)(5·5 − 3·7, −3·5 + 3·7) = (4/6, 6/6) = (0.667, 1): y = 0.667 + x.

Forudsigelser 0.667, 1.667, 2.667; residualer 0.333, −0.667, 0.333 (sum 0); sum af kvadrater 0.667. Ingen linje klarer det bedre (mindste kvadrater).
