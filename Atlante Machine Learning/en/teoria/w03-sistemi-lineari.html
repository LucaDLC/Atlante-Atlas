Linear systems, inverse, determinant

Learning a linear model means finding the weights that make many equations true together: a linear system. Here: how it is written with matrices, the two views (rows and columns), when it has one, no or infinitely many solutions, the column span, what the determinant measures, how the inverse is computed, and how it is solved in NumPy. Slides 51–65 of lecture 2.

From the system to the matrix: Ax = b

A linear system is a group of linear equations that must hold at the same time. The example of slide 51: two species that eat different quantities of two foods, and one asks how many there are knowing the total consumption. Each constraint is an equation.

It is written in compact form by gathering the numbers into three objects: the matrix of coefficients A (one row per equation), the vector of the unknowns x, the vector of the constant terms b. Then the whole system is Ax = b.

The row view: lines that cross

In the row picture (row picture) each equation is a geometric object: with two unknowns a line, with three a plane, with n a hyperplane (hyperplanes). Every point of the object makes that equation true.

The solution of the system is the point that makes all the equations true together: the intersection of all the lines. With 2x + y = 4 and x + 3y = 7 the two lines meet at (1, 2), and substituting one checks that both equations hold.

This view makes clear why one needs as many equations as unknowns: with one line alone the possible points are infinitely many; the second line chooses one.

One, no or infinitely many solutions

Two lines in the plane can be in only three ways, so a 2 × 2 system has only three possible outcomes (slide 53).

One solution: the lines cross at one point. No solution: the lines are parallel and distinct, they never meet (the equations contradict each other: x + 2y should be worth 3 and also 5). Infinitely many solutions: the lines coincide, because one equation is a multiple of the other and adds no information.

In the last two cases the rows of A are multiples of each other (linearly dependent) and the determinant is 0. If det ≠ 0 there is always one and only one solution, whatever b.

The column view: combining the columns

The same system can also be read by columns (slide 61, column picture): Ax = x·a₁ + y·a₂, where a₁ and a₂ are the columns of A. Solving Ax = b means finding how much of each column is needed to build b.

The solution is the same as in the row view, but the question is different and more useful in ML: "can the vector b be obtained by combining the columns?". If yes, the weights of the combination are the solution. If no, the system has no solution.

The column space and the span

The set of all the linear combinations of the columns of A is called the column space (column space), or the span of the columns. It is the set of the b for which Ax = b has a solution.

If the columns point in different directions, in 2D their span is the whole plane: every b is reached. If instead one column is a multiple of the other, the span shrinks to a line: the b on the line are reached in infinitely many ways, those outside never. Hence the sentence of slide 64: "vectors should span the space to have an inverse".

The number of really different directions among the columns is called the rank (rank): for [[1, 2], [2, 4]] it is 1. Span and rank return in week 6 (bases) and in least squares, where b usually does not lie in the column space and one looks for the nearest point.

The determinant

For a 2 × 2 matrix the determinant is det [[a, b], [c, d]] = ad − bc: product of the main diagonal minus product of the other diagonal. For [[2, 1], [1, 3]]: 2·3 − 1·1 = 5. For [[1, 2], [2, 4]]: 4 − 4 = 0.

Geometric meaning: |det A| is the factor by which A multiplies the areas. The unit square becomes the parallelogram formed by the columns, and its area is |det A|. The sign says whether A flips the orientation (like a mirror).

det ≠ 0: A squashes nothing, the system Ax = b has one single solution for every b, and A is invertible (also called non-singular). det = 0: A squashes the plane onto a line (or a point), the columns are dependent, the solutions are none or infinitely many, and A is not invertible (singular).

The inverse

The inverse of a square matrix A is the matrix A⁻¹ that "undoes" it: A⁻¹A = AA⁻¹ = I. It exists only if det A ≠ 0 (slide 65: invertible = non-singular).

It serves to solve the system with the same move as a balance: both sides of Ax = b are multiplied, on the left, by A⁻¹. On the left remains A⁻¹Ax = Ix = x, so x = A⁻¹b. "On the left" matters: the product of matrices is not commutative, and bA⁻¹ would not even have the right shapes.

Learning a model = solving a system

The link with ML (slide 52: "meaning of solving for model parameters in linear models"). In a linear model the unknowns are the weights; the data (x, y) are known numbers. Each measured point gives a linear equation in the weights, and the set of points gives a system.
