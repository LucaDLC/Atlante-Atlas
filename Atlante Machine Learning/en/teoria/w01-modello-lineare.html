The 1D linear model

The first model of the course is a line: one input x, one output y, two parameters. Here you find what the two parameters mean, why a line is a point in the "parameter space", how to find the line with two points, and what happens when parameters are added.

The line: intercept and slope

The linear regression model in one dimension (1D linear regression model) is

y = w₀ + w₁·x

Symbol by symbol. x is the input, a single number (for example the square metres of a house). y is the predicted output (the price). w₀ and w₁ are the parameters: fixed numbers, which the training must find. The subscripts 0 and 1 only serve to tell them apart: w₀ goes with x⁰ = 1, w₁ goes with x¹ = x.

w₀ is the intercept (intercept or y-offset): the value of y when x is 0, that is the point where the line crosses the vertical axis. Changing it moves the line up and down without rotating it.

w₁ is the slope (slope): how much y changes when x increases by 1. If it is positive the line rises, if it is negative it falls, if it is 0 the line is horizontal. Changing it rotates the line around the intercept.

The slides also call it an affine mapping: "linear plus a shift". The exact term (linear versus affine) returns in week 4.

Data space and parameter space

A line can be looked at in two ways (slide 28). In the data space (data space) the axes are x and y: the data are points, the model is a line.

In the parameter space (parameter space) the axes are w₀ and w₁. Since a line is described by two numbers, here every line becomes one point, and every point is a different line.

This change of viewpoint is the heart of the course: learning a model means looking for a point in the parameter space, the one where the loss is smallest. With 2 parameters you can draw it; with real models the space has many dimensions, but the search is the same.

Two points are enough: finding slope and intercept

A line has two unknowns, w₀ and w₁. Two measured points (x₁, y₁) and (x₂, y₂) give two equations, and two equations are enough for two unknowns (slide 29).

The slope is the ratio between how much y changes and how much x changes between the two points:

w₁ = (y₂ − y₁) / (x₂ − x₁) = Δy / Δx

The symbol Δ (capital delta) is read "change in". Then the intercept is obtained by putting one of the two points into the equation and isolating w₀: y₁ = w₀ + w₁·x₁ becomes w₀ = y₁ − w₁·x₁.

With the parameters found, the model makes predictions for any x. With more than two points that do not lie on a line, instead, no line passes through all of them: one looks for the one that is wrong the least, and the least squares loss is needed. The same exercise in system form is exercise 9 of the test (exercises by hand).

More parameters, more flexibility

The line is only the simplest model. Adding powers of x gives the polynomials (slide 31): degree 2 (2nd order) y = w₀ + w₁x + w₂x², degree 3 with also w₃x³, and so on. A polynomial of degree d has d + 1 parameters.

More parameters make the model more flexible (slide 32): it can bend to follow the data, and the loss on the training data goes down. With as many parameters as there are points, the polynomial passes exactly through all the points and the loss becomes 0.

But loss 0 is a trap: the model has bent also to chase the noise, and on new data it gets things more wrong. Choosing the right number of parameters is the problem of model complexity (week 7).

A detail that matters for the whole course: y = w₀ + w₁x + w₂x² is not a line in x, yet each parameter appears multiplied by a known number (1, x, x²) and added. The model is said to be linear in the parameters, and that is why it is learned with the same methods as the line.
