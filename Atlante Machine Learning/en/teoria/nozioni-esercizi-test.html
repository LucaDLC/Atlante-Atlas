Hand exercises for the in-class test

The first in-class test is on Monday 28 September, in the first 30–45 minutes of lesson 6: pen and paper, on the material of weeks 1–5 (if it goes badly, there is the resit in week 41). Here there are 14 exercises of the same type as the Grasple and in-class activities, each with the solution step by step. First try alone, then open the solution. All the results are checked with NumPy.

Vectors (weeks 1–2)

1. u = (1, 2, 2), w = (3, 0, 4). Calculate ‖u‖, ‖w‖ and the distance d(u, w).

Solution

‖u‖ = √(1 + 4 + 4) = √9 = 3. ‖w‖ = √(9 + 0 + 16) = √25 = 5.

u − w = (−2, 2, −2) ⇒ d = √(4 + 4 + 4) = √12 ≈ 3.46. First the squares, then the sum, then the root (norms).

2. Same vectors: inner product and angle.

Solution

u · w = 1·3 + 2·0 + 2·4 = 11. cos θ = 11 / (3 · 5) = 11/15 ≈ 0.733 ⇒ θ ≈ 42.8°.

3. Project w = (2, 3) onto the direction of u = (1, 1).

Solution

(u · w / u · u) · u = (5 / 2) · (1, 1) = (2.5, 2.5). Check: w − projection = (−0.5, 0.5), perpendicular to u (inner product 0).

4. The model f(x) = 2x + 1 on the data (1, 3), (2, 4), (3, 8). Calculate the least squares loss L = (1/N) Σ (yᵢ − f(xᵢ))².

Solution

Predictions: 3, 5, 7. Errors: 3 − 3 = 0, 4 − 5 = −1, 8 − 7 = 1. Squares: 0, 1, 1. L = 2/3 ≈ 0.667. N = number of points (3), not of models (loss).

Matrices and systems (week 3)

5. [[1, 2], [0, −1], [3, 1]] · (2, 1) = ? First the dimensions.

Solution

(3 × 2) · (2) → 3 numbers, one per row (dimensions). Row 1: 1·2 + 2·1 = 4. Row 2: 0·2 + (−1)·1 = −1. Row 3: 3·2 + 1·1 = 7. Result (4, −1, 7).

6. A = [[1, 2], [3, 4]], B = [[0, 1], [1, 0]]. Calculate AB and BA.

Solution

AB = [[1·0 + 2·1, 1·1 + 2·0], [3·0 + 4·1, 3·1 + 4·0]] = [[2, 1], [4, 3]] (swaps the columns of A).

BA = [[3, 4], [1, 2]] (swaps the rows of A). AB ≠ BA: the order matters.

7. A = [[2, 1], [5, 3]]. Determinant, inverse, and the solution of Ax = (1, 2).

Solution

det = 2·3 − 1·5 = 1. For a 2 × 2 [[a, b], [c, d]]: A⁻¹ = (1/det) [[d, −b], [−c, a]] = [[3, −1], [−5, 2]].

x = A⁻¹(1, 2) = (3·1 − 1·2, −5·1 + 2·2) = (1, −1). Check: 2·1 + 1·(−1) = 1 ✓, 5·1 + 3·(−1) = 2 ✓.

8. [[1, 2], [2, 4]] x = b. How many solutions with b = (3, 6)? And with b = (3, 5)?

Solution

det = 4 − 4 = 0: the second row is twice the first (rank 1).

b = (3, 6): the second equation is twice the first ⇒ only one equation, x₁ + 2x₂ = 3 ⇒ infinitely many solutions. b = (3, 5): 2x₁ + 4x₂ would have to be 6 and 5 at the same time ⇒ no solution (systems).

9. Find the line y = w₀ + w₁x through (1, 1) and (3, 5), writing the system.

Solution

w₀ + 1·w₁ = 1 and w₀ + 3·w₁ = 5. Subtracting: 2w₁ = 4 ⇒ w₁ = 2; then w₀ = 1 − 2 = −1. Line y = −1 + 2x. In matrix form: [[1, 1], [1, 3]] · [w₀, w₁] = [1, 5] (isolate w).

10. Are (1, 2, 3) and (2, 4, 6) independent? And (1, 0, 1), (0, 1, 1), (1, 1, 0)?

Solution

(2, 4, 6) = 2·(1, 2, 3): dependent. For the three vectors: the matrix that has them as columns has determinant −2 ≠ 0 ⇒ independent (and they are a basis of ℝ³) (bases).

Transformations and least squares (weeks 4–5)

11. R = rotation by 90°, [[0, −1], [1, 0]]; S = [[2, 0], [0, 1]]. Calculate R · (2, 1), then SR · (1, 0) and RS · (1, 0).

Solution

R · (2, 1) = (0·2 − 1·1, 1·2 + 0·1) = (−1, 2).

SR(1, 0): first R → (0, 1), then S → (0, 1). RS(1, 0): first S → (2, 0), then R → (0, 2). The rightmost matrix is applied first; the order changes the result (transformations).

12. Translate the point (1, 2) by (3, −1) using homogeneous coordinates.

Solution

[[1, 0, 3], [0, 1, −1], [0, 0, 1]] · [1, 2, 1] = [1 + 3, 2 − 1, 1] = (4, 1). The 1 added at the bottom multiplies the translation (homogeneous).

13. The degree 2 polynomial that passes through (−1, 2), (0, 1), (1, 2).

Solution

y = w₀ + w₁x + w₂x². From (0, 1): w₀ = 1. From (1, 2): 1 + w₁ + w₂ = 2. From (−1, 2): 1 − w₁ + w₂ = 2. Adding the last two: 2 + 2w₂ = 4 ⇒ w₂ = 1, so w₁ = 0. y = 1 + x².

14. Least squares line for (0, 1), (1, 1), (2, 3), with w = (AᵀA)⁻¹Aᵀy.

Solution

A = [[1, 0], [1, 1], [1, 2]], y = (1, 1, 3). AᵀA = [[3, 3], [3, 5]] (top: how many points; then Σx; bottom Σx²). Aᵀy = (Σy, Σxy) = (5, 7).

det(AᵀA) = 15 − 9 = 6; (AᵀA)⁻¹ = (1/6) [[5, −3], [−3, 3]]. w = (1/6)(5·5 − 3·7, −3·5 + 3·7) = (4/6, 6/6) = (0.667, 1): y = 0.667 + x.

Predictions 0.667, 1.667, 2.667; residuals 0.333, −0.667, 0.333 (sum 0); sum of squares 0.667. No line does better (least squares).
