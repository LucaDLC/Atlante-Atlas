Noise, data and generalisation

Lecture 6. A model does not learn from "true" data, but from dirty measurements: noise, outliers, missing data. Here is the model that the course uses to describe the data (Y = f + N), the types of noise, and why the aim is not to remember the training data but to generalise. DW chapter 8.

If the model is too simple, even the part of f that the model cannot represent looks like "noise". Example from the book: data with a wave-like trend, read with a linear model. Before calling it noise, ask whether it is the model that is wrong.

Handling noise

  • Averaging: random noise has mean 0, so averaging many samples reduces it. It is what the assignment does, taking the mean pupil centre for each target.
  • Filtering: a local average, for example on a signal over time or on an image (week 7).
  • More data: they attenuate random noise, not systematic noise.
  • Simpler or regularised models, which cannot chase every oscillation (week 7).
  • Removing outliers, with caution.

An outlier is not necessarily an error: in fiscal or medical data the extreme cases can be exactly the frauds or the diseases of interest. And removing the "awkward" points makes the data look nicer than they are: the model will seem better than it is.

Describing the data

A random variable is a quantity whose value depends on a random process: the noise N, the centre of the pupil in a frame, the height of a person taken at random. Its value is not known, but its distribution can be described.

Learning means generalising

"We model the observations as Y = f(x) + N(x): an unknown underlying function plus noise. Learning means estimating f, not memorising Y."

"Random noise averages out; systematic noise does not, so more data cannot fix it."

"Inductive bias is the set of assumptions that lets a model predict outside the training data, for example linearity in linear regression."
