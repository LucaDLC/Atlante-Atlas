A convex function (bowl-shaped, positive second derivative) has a single minimum, and gradient descent finds it. The loss of a network is not convex: one can end in a local minimum, and the starting point matters.

Activation functions: why they are needed

Each neuron does two things: an inner product z = wᵀx (as in linear regression) and then an activation function g(z). Without activation, a network with many layers would be useless: two linear layers W₂(W₁x) are the same as a single matrix (W₂W₁)x, so the whole network would remain a linear model.

The activations of the course: the sigmoid σ(z) = 1/(1 + e⁻ᶻ), between 0 and 1, which is read as a probability (logistic regression, output for two classes); the tanh, same shape between −1 and 1; the ReLU max(0, z), the standard choice in the hidden layers, because it is simple and its derivative does not switch off for large z (that of the sigmoid does, and training slows down). On the output the activation is chosen according to the task: identity for regression (the gaze network predicts two numbers), sigmoid or softmax for classification.

With a non-linearity between the layers, combining neurons produces new functions: for example |z| = ReLU(z) + ReLU(−z), a V that no linear model can represent. A neural network is therefore a non-linear prediction function: a composition of linear transformations and non-linearities, whose weights are learned by gradient descent.
