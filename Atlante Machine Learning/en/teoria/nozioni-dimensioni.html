Dimensions in products between matrices

Before multiplying, check the dimensions: five seconds are enough. It is the most common error in hand exercises, and it is also the most common ValueError in NumPy.

The basic rule

A product (m × n) · (p × q) is defined only if n = p, that is if the two numbers "in the middle" coincide. The result has the dimensions of the two outer numbers: m × q.

(2 × 3) · (3 × 1) ✅ → result 2 × 1 · (2 × 3) · (2 × 1) ❌ → not defined.

In practice: columns of the first = rows of the second.

Write the dimensions under each factor and cancel the pairs in the middle: (m × n)(n × q) → m × q. It works also with more factors: (2 × 3)(3 × 4)(4 × 1) → 2 × 1.

Vector on the right: matrix · vector

The vector is a column. Its length must be equal to the number of columns of the matrix. The result has as many elements as the matrix has rows: one number per row.

Vector on the left: vector · matrix

The vector is a row. Its length must be equal to the number of rows of the matrix. It is always the rule of the numbers in the middle: (1 × 2) · (2 × 3) ✅ → 1 × 3. The result has one number per column.

Addition and subtraction require identical dimensions because one operates cell by cell: each cell of A needs its partner in B.

They are two independent rules. With A: n × m and B: p × q: addition asks for n = p and m = q; the product asks only for m = p. The same pair can pass one check and fail the other:

ShapesA + BA · B
(2 × 3) e (2 × 3)✅ identical shapes❌ in the middle 3 ≠ 2
(2 × 3) e (3 × 2)❌ different shapes✅ in the middle 3 = 3 → 2 × 2

To remember it: in addition the two shapes are put one above the other and must coincide, both; in the product they are put one next to the other and only the numbers in the middle must coincide.

n × m is the shape of a single matrix: n rows and m columns. The × sign is read "by", but it does not multiply two matrices. To talk about two matrices we need four numbers, two for each. The constraint "columns of the first = rows of the second" holds only for the product. Addition and subtraction do not "extend" it: they only ask for identical shapes.

The four combinations were checked with NumPy: A + B → (2, 3), A @ C → (2, 2); A @ B and A + C → ValueError.

Never add rows, columns or zeros to make the dimensions match: one would change the problem. If the numbers in the middle do not coincide, the answer is "not defined".

The same holds for the transpose: with A 2 × 3 and C 3 × 2, A + C is not defined. A + Cᵀ instead can be done (Cᵀ is 2 × 3), but it is a different operation, with different numbers. One transposes only if the text asks for it.

The intuition is right only with respect to the original C: row i of A goes with column i of C, that is Aij + Cji. Two roads, same result: write Cᵀ and add normally (recommended), or pair the row of A with the column of C. The "direction" row → / column ↓ exists only in the product.

Addition becomes possible: A = [[1, 2, 3], [4, 5, 6]], C = [[1, 4], [2, 5], [3, 6]], A + Cᵀ = [[2, 4, 6], [8, 10, 12]]. But you have calculated A + Cᵀ, not A + C. If the question is A + C, the answer stays "not defined". (Checked with NumPy.)

The typical error

One adds inside a single row × column (it is the inner product), never between different rows: each row produces a separate cell of the result.

Right: (8, 14)

[[4, −4], [4, −1]] · (4, 2)

row 1: 4·4 + (−4)·2 = 16 − 8 = 8
row 2: 4·4 + (−1)·2 = 16 − 2 = 14

2 × 2 matrix times vector of 2 → vector of 2.

Wrong: 22

8 + 14 = 22 adds the results of two different rows.

A single number comes out only from the inner product of two vectors. From a matrix times a vector a vector always comes out.

In NumPy

NumPy applies exactly the same rules, with two particularities. The matrix product is written @ (never *, which multiplies cell by cell). And a 1D array, of shape (n,), is neither row nor column: NumPy treats it as a column if it is on the right of @ and as a row if it is on the left. When something does not work, the first check is always the .shape of each factor.

All the results and error messages were obtained by running the code (NumPy 2.4.6).

Where you need it in the course

Every formula of the course with matrices and vectors can be checked with the shapes, without remembering it by heart: if the dimensions do not match in some step, the formula is written wrong.
