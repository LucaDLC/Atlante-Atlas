Least squares loss

A number that says how much a model gets wrong on the data. It is computed error by error: first the square, then the sum, then the mean. Here: the formula symbol by symbol, the order of the operations, a worked example, why precisely the square, and the loss seen as a function of the parameters. Exercise 3 of week 1 (Evaluating Models, Grasple).

The formula and its symbols

The loss (in Italian "perdita", or cost function) is a single number that summarises how much the model gets wrong on all the data. The smaller it is, the better the model fits. That of least squares (least squares loss) is:

Lf = 1N ∑i=1N (yi − f(xi))2
SymbolMeaning
xithe input of point i: it enters the function
yithe label of point i: the true answer
f(xi)the prediction of the model
yi − f(xi)the error (residual) on point i
Nthe number of points in the dataset, not of models
∑i=1Nsum over i from 1 to N: it runs through the points

It is read from inside out. For each point: put xi in the model, compare with the truth yi, square the error. Then sum all the squares and divide by how many there are. The result is the mean of the squared errors, which in the metrics of week 11 is called MSE (mean squared error).

The loss does not say where the model errs, only how much in total. It serves to compare models: with two models two losses are computed, and the lower one wins.

The index of the sum is i, the same as xi and yi: so N counts the points, not the variables or the functions. With two models the formula is applied twice, separately, and one obtains two losses to compare.

Power first or sum first?

The most common doubt about the formula (also asked in chat): is the 2 applied before or after the Σ? The answer lies in the brackets. The 2 is attached to the bracket (yi − f(xi)), which is inside the summation: it belongs to each single term. So first the square of each error, then the sum.

Read from the inside outwards: bracket → square → sum → division by N.

Square first (right)

(−4)2 + (−15)2 + (−32)2

= 16 + 225 + 1024 = 1265

Sum first (wrong)

(−4 − 15 − 32)2

= (−51)2 = 2601

The order is not a convention: it changes the meaning. Summing first, the positive and negative errors cancel out, and a model that errs everywhere can get 0, that is "perfect". The square on each error makes them all positive before summing them.

If you see (∑ …)2, with the bracket enclosing the sum, then yes, one sums first. In the loss there is none.

Worked example

Data (2, 5), (3, 7), (4, 9): the first number is the input, the second the label. Model f1(x) = 3x2 − 2x + 1. The formula is applied point by point, exactly in the order of the section above.

Shows the loss of f2(x) = 2x² + 4x + 3

Predictions 19, 33, 51. Errors −14, −26, −42. Squares 196, 676, 1764. Sum 2636. L ≈ 878.7. So f1 is better.

The data lie exactly on the line y = 2x + 1, which would have loss 0. Both models are quadratic, so they have the wrong shape. The errors of f1 grow systematically (−4, −15, −32): it is the sign of a problem of the model, not of noise. It will be called bias in week 6.

Why the square and not the absolute value

To prevent the errors from cancelling out it would be enough to remove the sign, that is to use the absolute value |yᵢ − f(xᵢ)|. So why precisely the square? Three reasons.

1. It weighs large errors more. An error of 0.5 costs 0.25, one of 3 costs 9. The model is pushed above all to avoid big mistakes. The other side of the coin: a single anomalous datum (outlier) can move the result a lot.

2. It is smooth. The graph of e² is a curve without corners, that of |e| has a point at 0. Smooth curves can be minimised with derivatives and, in the case of linear models, with an exact formula (the normal equations of week 5).

3. It has a single minimum. For models linear in the parameters the squared loss is a "bowl" with a single bottom, as the next section shows: there are no traps.

The mean of the absolute value does not disappear: it is called MAE (mean absolute error) and is used as an evaluation metric in week 11.

The loss depends on the parameters

Up to here the model was fixed and its loss was computed. Now the point of view is reversed: the data are fixed and it is the parameters that change. For every choice of the parameters one obtains a different loss, so the loss is a function of the parameters: it is written L(w).

Learning means finding the parameters where L(w) is minimal: it is the meaning of "minimizing the least squares" (slide 36). With a single free parameter everything can be seen in one graph: the loss draws a parabola, because it is a sum of squared terms in the parameter, and the minimum is its bottom.

With two parameters (w₀ and w₁) the parabola becomes a 3D "bowl", with many parameters a bowl in many dimensions. The bottom is found with linear algebra (least squares) or by going down step by step along the slope (gradient descent).
