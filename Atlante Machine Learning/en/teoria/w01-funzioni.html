Functions and composition

An ML model is a function, and almost always a chain of functions. Here: what the word function means, how to read the graph, the three types of function that the slides distinguish, how functions are composed and decomposed, and why it matters. Exercises 5 and 6 of week 1 (Functions and Function Composition, Grasple).

What a function is

A function is a rule that associates with each input one single result. It is written with a letter (usually f) followed by the input in brackets: f(x) = 2x + 1 means "the function f takes a number x, doubles it and adds 1".

The letter x is a placeholder: it has no value of its own. Evaluating the function at a number means substituting that number for x everywhere it appears. f(3) = 2·3 + 1 = 7 is read "f of 3 is 7".

The set of admitted inputs is called the domain; the set where the results fall is the codomain. The notation f: ℝ → ℝ says exactly this: f takes a real number and returns a real number.

The rule "one input, one single output" is what makes a function useful as a model: given the same x, the prediction must always be the same.

The graph of a function

The graph of f is the set of all the points (x, f(x)): for every input on the horizontal axis you go up to the height of the result. It serves to see at a glance how the function behaves: where it rises, where it falls, where it is zero.

Reading it the other way round is a quick way to check whether a curve is the graph of a function: the vertical line test. A vertical line fixes an x; if it touches the curve at more than one point, that x would have more results, and the curve is not a function of x.

In the course the graphs serve mostly for regression models: the data are points, the model is a curve, and the error of each point is the vertical distance between the point and the curve.

One variable, several variables, vector values

Slide 25 of lecture 1 distinguishes three types of function, and the course uses them all.

Single-valued function of one variable (single valued function), f: ℝ → ℝ: a number goes in, a number comes out. The 1D linear model is of this type.

Of several variables (multivariate function), f: ℝⁿ → ℝ: a vector of n numbers goes in, a number comes out. For example f(x₁, x₂) = 2x₁ + 3x₂. It is the form of regression with several features: the graph is no longer a curve, but a plane or a hyperplane (lines, planes, hyperplanes).

With vector values (multivariate vector function), f: ℝⁿ → ℝᵐ: a vector goes in, another vector comes out. For example f(x₁, x₂) = (x₁ + x₂, x₁ − x₂). The geometric transformations of week 4 and the model of Assignment 1, which predicts two screen coordinates from the pupil position, are of this type.

Composing two functions

Composing means putting two functions in a row: the output of the first becomes the input of the second. It is written f(g(x)), or (f ∘ g)(x), and the symbol ∘ is read "after": f after g.

It is computed from inside to outside: first the innermost function (g), then the one that wraps it (f). With g(x) = x + 1 and f(x) = x²: f(g(2)) = f(3) = 9.

The order matters. g(f(2)) = g(4) = 5, a different result. In general f(g(x)) ≠ g(f(x)): composition is not commutative. This fact returns identically with matrices, where "apply R first and then S" gives a different result from "S first and then R" (transformations).

Decomposing a function

The exercise in reverse: given a complicated function, recognise the simple functions it is made of. In h(x) = (3x − 1)² there are two operations: first 3x − 1 is computed, then it is squared.

The inner function is g(x) = 3x − 1, the outer one is f(u) = u². The letter u is just a name for the input of f, to remind you that it is not x but the result of g. So h = f ∘ g.

How to find the inner function: look at what the last operation would be if you computed h with a number. That is the outer function; everything underneath is the inner function. Decomposing in this way is the first step of the chain rule, which is used to compute derivatives (weeks 8 and 14).

Why machine learning is made of compositions

In the pipeline of the first lecture each block is a function: cleaning takes a raw datum and returns a clean one, the computation of features takes a datum and returns a vector, the model takes a vector and returns a prediction. The final prediction is therefore a composed function: ŷ = f(Φ(n(x))).

Two practical consequences. First: each piece of the chain must be applied identically in training and in prediction, otherwise the model receives inputs different from those it learned on. Second: to train a chain of functions with gradient descent you must differentiate a composed function, and the tool is the chain rule. A neural network is exactly a long composition of simple functions (week 14).
