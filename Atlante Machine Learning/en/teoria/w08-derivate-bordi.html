Gradient of an image and edges

An image is a function of two variables, I(x, y). Filtering with a derivative filter in x gives the image of the derivatives Ix; in y, Iy. At each pixel the gradient is ∇I = (Ix, Iy).

Filterfor xIdea
differences[−1, 1]the simplest, very sensitive to noise
Prewitt[[−1, 0, 1], [−1, 0, 1], [−1, 0, 1]]central difference averaged over 3 rows
Sobel[[−1, 0, 1], [−2, 0, 2], [−1, 0, 1]]like Prewitt, with the central row weighing double (a bit of Gaussian smoothing)

The filter for y is the same rotated (the transpose).

With convolve the filter is flipped, so Sobel x on a passage from dark to bright (towards the right) gives negative values (verified: −4 instead of +4 on a step from 0 to 1). For the magnitude of the gradient nothing changes; for the direction it does.

Canny (preprocessing of Assignment 1) finds the edges from the magnitude of the gradient. HOG (week 11) divides the image into cells and in each makes a histogram of the directions of the gradient, weighted by the magnitude: a feature for classifying. The gradient of a loss is what makes neural networks learn (week 14).
