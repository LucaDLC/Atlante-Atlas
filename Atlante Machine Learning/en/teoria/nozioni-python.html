Reading an element: the indices

a[i] reads the element in position i, and one counts from 0. With a = [2, 2, 5]: a[0] is 2, a[2] is 5, a[-1] is the last (5). In a NumPy matrix: M[i, j] = row i, column j. Slices and columns are in the page Indexing NumPy arrays.

The inner product written by hand

The exercise of week 1: writing dot(a, b) without NumPy. Here are all the pieces you had asked about: comparing two lengths, a counter inside the for, reading two lists together.

for x, y in zip(a, b): the pairs (the most readable). for i in range(len(a)) and then a[i] * b[i]: with the index. for i, x in enumerate(a): index and value together (enumerate(['a', 'b']) gives (0, 'a'), (1, 'b')).

Tuples: ms = 4, 6, 7

The commas without brackets create a tuple of 3 numbers: (4, 6, 7). They are not pairs. To run through pairs of poses one needs a list of pairs.

ms = 4, 6, 7
for i, j in ms:
    plot_pair(poses[i], poses[j])
TypeError: cannot unpack non-iterable int object

The for takes one element at a time: first the 4. i, j tries to split the 4 into two values, and a number does not split. Right: ms = [(0, 1), (2, 3)]: each element is a pair, and i, j unpacks it.

Classes: the ... under a method

A class groups data and functions. A function inside a class is called a method and always receives self as the first parameter: it is the object itself, so self.k reads or writes a datum of the object.

In the gaze the class GazeModel is a base: it declares the methods calibrate and predict without writing them. LinearGaze extends it (class LinearGaze(GazeModel)) and really writes them. The advantage: predict_many is written only once in the base and calls self.predict, so it works for every model that extends it.

The ... (in English Ellipsis) is a placeholder: Python accepts it as a statement that does nothing. The body of the method is not written, so the function returns None.

In the notebook the base has calibrate(self, dataset) and the daughter calibrate(self, dataset, pupil_training_set, screen_training_set). Python does not check: the daughter replaces the base and uses its own signature. If you call a method with arguments that the class does not have, the error appears only at runtime.
