The specificity in the notes is called "False Negative Rate". This is wrong: the specificity is the True Negative Rate, TN / (TN + FP). The false negative rate is FN / (FN + TP) = 1 − recall.

Unbalanced classes

RemedyHowRisk
undersamplingremove examples of the large class at randominformation is thrown away
oversamplingduplicate examples of the small class at randomoverfitting on the duplicates
SMOTE (data augmentation)create synthetic examples between neighbours of the small classunrealistic examples
sample weights (sample reweighting)change the loss: the examples of the small class count for more, so an error on them weighs as much as many errors on the large classtoo much weight on few examples amplifies the noise
suitable metrics, stratified CV, class weightsF1, MCC, PR-curve; folds with the same proportions–

The three techniques are those of the reading Class Imbalance: Random Sampling and Data Augmentation with Imbalanced-Learn. The resampling is done only on the training: the test must stay as it is in reality.
