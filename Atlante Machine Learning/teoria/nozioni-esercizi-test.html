Esercizi a mano per l'in-class test

Il primo in-class test è lunedì 28 settembre, nei primi 30–45 minuti della lezione 6: carta e penna, sul materiale delle settimane 1–5 (se va male, c'è il resit in settimana 41). Qui ci sono 14 esercizi dello stesso tipo delle attività Grasple e in-class, ognuno con la soluzione passo per passo. Prima prova da solo, poi apri la soluzione. Tutti i risultati sono controllati con NumPy.

Vettori (settimane 1–2)

1. u = (1, 2, 2), w = (3, 0, 4). Calcola ‖u‖, ‖w‖ e la distanza d(u, w).

Soluzione

‖u‖ = √(1 + 4 + 4) = √9 = 3. ‖w‖ = √(9 + 0 + 16) = √25 = 5.

u − w = (−2, 2, −2) ⇒ d = √(4 + 4 + 4) = √12 ≈ 3.46. Prima i quadrati, poi la somma, poi la radice (norme).

2. Stessi vettori: prodotto interno e angolo.

Soluzione

u · w = 1·3 + 2·0 + 2·4 = 11. cos θ = 11 / (3 · 5) = 11/15 ≈ 0.733 ⇒ θ ≈ 42.8°.

3. Proietta w = (2, 3) sulla direzione di u = (1, 1).

Soluzione

(u · w / u · u) · u = (5 / 2) · (1, 1) = (2.5, 2.5). Controllo: w − proiezione = (−0.5, 0.5), perpendicolare a u (prodotto interno 0).

4. Il modello f(x) = 2x + 1 sui dati (1, 3), (2, 4), (3, 8). Calcola la loss dei minimi quadrati L = (1/N) Σ (yᵢ − f(xᵢ))².

Soluzione

Previsioni: 3, 5, 7. Errori: 3 − 3 = 0, 4 − 5 = −1, 8 − 7 = 1. Quadrati: 0, 1, 1. L = 2/3 ≈ 0.667. N = numero di punti (3), non di modelli (loss).

Matrici e sistemi (settimana 3)

5. [[1, 2], [0, −1], [3, 1]] · (2, 1) = ? Prima le dimensioni.

Soluzione

(3 × 2) · (2) → 3 numeri, uno per riga (dimensioni). Riga 1: 1·2 + 2·1 = 4. Riga 2: 0·2 + (−1)·1 = −1. Riga 3: 3·2 + 1·1 = 7. Risultato (4, −1, 7).

6. A = [[1, 2], [3, 4]], B = [[0, 1], [1, 0]]. Calcola AB e BA.

Soluzione

AB = [[1·0 + 2·1, 1·1 + 2·0], [3·0 + 4·1, 3·1 + 4·0]] = [[2, 1], [4, 3]] (scambia le colonne di A).

BA = [[3, 4], [1, 2]] (scambia le righe di A). AB ≠ BA: l'ordine conta.

7. A = [[2, 1], [5, 3]]. Determinante, inversa, e la soluzione di Ax = (1, 2).

Soluzione

det = 2·3 − 1·5 = 1. Per una 2 × 2 [[a, b], [c, d]]: A⁻¹ = (1/det) [[d, −b], [−c, a]] = [[3, −1], [−5, 2]].

x = A⁻¹(1, 2) = (3·1 − 1·2, −5·1 + 2·2) = (1, −1). Controllo: 2·1 + 1·(−1) = 1 ✓, 5·1 + 3·(−1) = 2 ✓.

8. [[1, 2], [2, 4]] x = b. Quante soluzioni con b = (3, 6)? E con b = (3, 5)?

Soluzione

det = 4 − 4 = 0: la seconda riga è il doppio della prima (rango 1).

b = (3, 6): la seconda equazione è il doppio della prima ⇒ un'equazione sola, x₁ + 2x₂ = 3 ⇒ infinite soluzioni. b = (3, 5): 2x₁ + 4x₂ dovrebbe valere 6 e 5 insieme ⇒ nessuna soluzione (sistemi).

9. Trova la retta y = w₀ + w₁x per (1, 1) e (3, 5), scrivendo il sistema.

Soluzione

w₀ + 1·w₁ = 1 e w₀ + 3·w₁ = 5. Sottraendo: 2w₁ = 4 ⇒ w₁ = 2; poi w₀ = 1 − 2 = −1. Retta y = −1 + 2x. In forma matriciale: [[1, 1], [1, 3]] · [w₀, w₁] = [1, 5] (isolare w).

10. (1, 2, 3) e (2, 4, 6) sono indipendenti? E (1, 0, 1), (0, 1, 1), (1, 1, 0)?

Soluzione

(2, 4, 6) = 2·(1, 2, 3): dipendenti. Per i tre vettori: la matrice che li ha come colonne ha determinante −2 ≠ 0 ⇒ indipendenti (e sono una base di ℝ³) (basi).

Trasformazioni e minimi quadrati (settimane 4–5)

11. R = rotazione di 90°, [[0, −1], [1, 0]]; S = [[2, 0], [0, 1]]. Calcola R · (2, 1), poi SR · (1, 0) e RS · (1, 0).

Soluzione

R · (2, 1) = (0·2 − 1·1, 1·2 + 0·1) = (−1, 2).

SR(1, 0): prima R → (0, 1), poi S → (0, 1). RS(1, 0): prima S → (2, 0), poi R → (0, 2). Si applica prima la matrice più a destra; l'ordine cambia il risultato (trasformazioni).

12. Trasla il punto (1, 2) di (3, −1) usando le coordinate omogenee.

Soluzione

[[1, 0, 3], [0, 1, −1], [0, 0, 1]] · [1, 2, 1] = [1 + 3, 2 − 1, 1] = (4, 1). L'1 aggiunto in fondo moltiplica la traslazione (omogenee).

13. Il polinomio di grado 2 che passa per (−1, 2), (0, 1), (1, 2).

Soluzione

y = w₀ + w₁x + w₂x². Da (0, 1): w₀ = 1. Da (1, 2): 1 + w₁ + w₂ = 2. Da (−1, 2): 1 − w₁ + w₂ = 2. Sommando le ultime due: 2 + 2w₂ = 4 ⇒ w₂ = 1, quindi w₁ = 0. y = 1 + x².

14. Retta ai minimi quadrati per (0, 1), (1, 1), (2, 3), con w = (AᵀA)⁻¹Aᵀy.

Soluzione

A = [[1, 0], [1, 1], [1, 2]], y = (1, 1, 3). AᵀA = [[3, 3], [3, 5]] (in alto: quanti punti; poi Σx; in basso Σx²). Aᵀy = (Σy, Σxy) = (5, 7).

det(AᵀA) = 15 − 9 = 6; (AᵀA)⁻¹ = (1/6) [[5, −3], [−3, 3]]. w = (1/6)(5·5 − 3·7, −3·5 + 3·7) = (4/6, 6/6) = (0.667, 1): y = 0.667 + x.

Previsioni 0.667, 1.667, 2.667; residui 0.333, −0.667, 0.333 (somma 0); somma dei quadrati 0.667. Nessuna retta fa meglio (minimi quadrati).
