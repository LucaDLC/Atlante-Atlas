Code: Dijkstra in Java

Dijkstra with a PriorityQueue: provisional distances, priority queue with a comparator, relaxation and the stale-entry technique.

Weighted graph and distances

Each edge is a pair {neighbour, weight} in the list of the node. Distances start from infinity, except for the source.

  • new int[]{v, w} creates an array already filled with these values: the syntax is an array initializer.

Priority queue and relaxation

The queue has the smallest distance at the head. Each time I find a better distance, I put it back in the queue.

  • The continue jumps to the next round of the while.
  • No decrease-key is needed: several copies are inserted and the old ones are discarded. Cost O(m log m), equivalent to O(m log n).
