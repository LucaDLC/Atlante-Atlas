Code: bipartite matching in Java

The maximum matching with augmenting paths (Kuhn's version, equivalent to flow): recursion with an array of visited nodes.

Recursive augmenting path

For each element of L I look for a free receiver, or I move the current partner to another choice.

  • || is the logical "or" with short-circuit evaluation: if the first is true, the second (the recursion) is not called.
