BFS with the queue

The queue is an ArrayDeque: add puts at the back, poll removes from the front. dist[v] = -1 means "not yet seen", and the node is marked when it enters the queue.

  • Integer → int in int u = coda.poll();: the automatic conversion is called unboxing.
  • ArrayDeque is faster than LinkedList as a queue; it does not accept null.
  • StringBuilder accumulates the text and prints it only once: printing line by line on large outputs is slow.
