Code: Bellman-Ford in Java

Shortest paths with negative weights: n − 1 rounds of relaxation over all the edges, and the negative-cycle check with one more round.

The relaxation rounds

Each round scans all the edges. After n − 1 rounds the distances are final, if there are no negative cycles.

  • final on the variable: the value no longer changes after the assignment.
  • Negative weights are not a problem for Java: they are integers like the others.

The negative cycle

One more round: if a distance still improves, there is a negative cycle reachable from the source.

  • return inside main stops the program.

Running it

Example of input and output (actually compiled and run).

4 5 0
0 1 4
0 2 5
1 2 -3
2 3 2
1 3 6

(output)
0 0
1 4
2 1
3 3
