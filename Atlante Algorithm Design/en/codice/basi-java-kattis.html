The starting template

Almost every Kattis problem has this form: read the number of cases, read the lines, compute, print.

  • import java.io.*; and import java.util.*;: the asterisk imports all the classes of the package.
  • throws IOException: readLine() can fail, and Java requires you to declare it.
  • The name of the public class must match the file name: here Main.
