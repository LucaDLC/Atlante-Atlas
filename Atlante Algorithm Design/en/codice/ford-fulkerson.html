Code: Ford-Fulkerson in Java

The maximum flow with augmenting paths: matrix of residual capacities, BFS on the residual network, bottleneck and cancellation of the flow.

The residual network

The residual capacity is a matrix: cap[u][v] is how much I can still send from u to v. Suitable for small graphs.

  • static on the class's global variables: the main method uses them without passing them.

Augmenting path

A BFS on the residual network finds a path s→t. The bottleneck is the minimum capacity along the path: that amount passes.

  • The for that climbs the parents goes from t to s: to reconstruct the path backwards.

Running it
