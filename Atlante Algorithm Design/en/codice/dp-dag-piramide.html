Code: pyramid (Tower) in Java

DP from the bottom up on a pyramid: arrays of rows with growing length, and the maximum of the two children.

Reading the pyramid

Each level r has r + 1 values: an array of variable length for each row.

  • new int[n][] leaves the rows empty: they are sized afterwards. It is the way to have jagged arrays.

Climbing the pyramid

The last row is the base case. Each row above takes its own value plus the maximum of the two children.

  • Only two rows are needed in memory at any time: the new row replaces the old one.

Running it

Example of input and output (actually compiled and run).

3
1
1 2
2 0 0

(output)
massimo 4
