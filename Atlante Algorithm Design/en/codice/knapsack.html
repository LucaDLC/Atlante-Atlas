Code: knapsack in Java

The knapsack table opt[i][w] in Java: filling row by row, and the traceback to reconstruct the chosen objects.

The table

The table has (n + 1) × (W + 1) cells. Row 0 and column 0 are the base cases: Java initialises them to 0 by itself.

  • Math.max(a, b) is the library function: there is no need to write the if by hand.
  • The outer loop on i and the inner one on w respect the order of computation: each cell depends only on rows already computed.

Traceback: which objects

I start from the final cell and go back up. If the cell differs from the row above, object i was taken and the budget goes down.

  • Collections is in java.util: reverse, sort, max are utilities for lists.

Running it

Example of input and output (actually compiled and run).

3 6
1 1
2 6
5 18

(output)
valore 19, oggetti [1, 3]
