Code: DFS in Java

The recursive DFS: visit, visit order, connected components and cycle detection. With the syntax notes on static fields and recursion.

The recursive visit

DFS is a function that calls itself on the unseen neighbours. The system's call stack does the work of the stack.

  • static: the field or method belongs to the class, not to the object. Here main is static, so everything it uses is static.
  • ! is negation; a boolean[] is initialised entirely to false.
  • In Java the depth of the recursion is limited: on graphs with millions of nodes an explicit stack is needed.

Connected components

The outer loop starts a DFS from each node not yet seen. Each start is a new component.

  • componenti++ is componenti = componenti + 1.
