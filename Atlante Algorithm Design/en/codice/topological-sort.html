Code: topological sort in Java

Kahn's method: incoming degrees, a queue of sources, and cycle detection when not all the nodes get written.

Incoming degrees and queue

The edges are directed: adj.get(u) contains the successors of u, and entrante[v] counts how many edges enter v.

  • int[] has a fixed length and default values 0 (for boolean it would be false).
  • == compares the values of primitives; .equals is used for objects such as String.

Removing the nodes

Each extracted node is written in the order, and its outgoing edges are deleted by lowering the degree of the successors.

  • List<Integer> ordine = new ArrayList<>(): ordine.get(i) reads an element, .size() counts.

Detecting the cycle

If the graph has a cycle, the nodes of the cycle never reach degree 0: they stay unwritten. So counting is enough.

  • println starts a new line; print does not. Here I use print on the output built.

Running it

Example of input and output (actually compiled and run).

5 5
0 2
1 2
0 4
