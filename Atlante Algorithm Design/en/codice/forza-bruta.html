Code: vertex cover by brute force

All the subsets of nodes, encoded as the bits of an integer, with the edge check and the bit count with bitCount.

Subsets as bits

The number k from 0 to 2ⁿ − 1 represents a subset: bit i says whether node i is chosen.

  • >> is the right shift, & is the bitwise AND, << is the left shift.
  • Cost O(2ⁿ · m): exponential, but correct for small n.

Running it

Example of input and output (actually compiled and run).

3 3
0 1
1 2
0 2

(output)
vertex cover minima: 2
