Code: graphs as adjacency lists

How to build a graph in Java, how to compute the degree of a node, how to check an edge. It is the basic code on which BFS, DFS and topological sort rest.

Reading the graph

The graph arrives as text: first line n m, then m lines with the edges. I store it as an adjacency list: a list of neighbours for each node.

  • import java.io.*; and import java.util.*; import all the classes of the two packages.
  • throws IOException: readLine() can fail, and Java requires you to declare it (a checked exception).
  • new ArrayList<>(): the diamond <> tells Java to infer the type from the context.

Degree and the edge question

The degree of u is the size of its list. Checking the edge u–v means searching for v in the list of u: it costs the degree of u.

  • .size() is the number of elements of a list; .length is only for arrays.
  • int u = 0, v = 3; declares several variables of the same type on one line.
