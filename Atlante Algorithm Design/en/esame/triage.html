Triage: recognising the paradigm

How to recognise the family of a problem never seen before, in seven observations, with a decision tree and the signals of the text.

The seven observations

On each problem make these observations in order. The first three are almost always enough; the others separate greedy, DP and NP-hard.

  1. What comes out? A yes/no, a number, a set, a sequence. If a count comes out ("as many as possible", "fewest") or a sum of values ("maximise total pages"), flag it: that is the difference between greedy and DP.
  2. What structure ties the objects together? None (independent list) → greedy, knapsack or Partition. A linear order (sequence, string, intervals, pyramid) → DP. An explicit or hidden graph (grid, "infects", "prerequisite") → traversal, flow or NP-hard. Two sets to connect → flow.
  3. If there is a graph, what does it ask about paths? Does one exist? The shortest? Which nodes can I reach? → traversal (BFS, DFS, Dijkstra). More disjoint paths, or the minimum to destroy to separate → flow (Menger). A path that touches all the nodes, or a node cover → NP-hard, unless the graph is a tree or a DAG.
  4. Are there objects to assign with a limit? "each … exactly one", "at most c(i)", "cannot be used twice". Yes → flow: source → side A → side B → sink.
  5. Is there a single numerical budget? You maximise the number of objects → greedy, take the cheapest. You maximise a sum of values → DP knapsack.
  6. Try the most natural greedy on 3–4 objects. You find a counterexample → it is not greedy: it is DP or NP-hard. You do not find one and can say why it holds → greedy.
  7. Fix a parameter at an extreme value (t = 0, k = 2, r = n, all nodes red): if it becomes Independent Set, Vertex Cover, Hamiltonian path, 3SAT or Set Cover, it is NP-hard, and you already have the reduction.

The method in the exam room (4 hours)

  1. Read the 5 problems only for output and constraint. In the margin write what is optimised, on which structure, with which constraints.
  2. Assign the sure ones first: flow (two sets to pair) and traversal (reachability, distances).
  3. Eliminate: what remains is greedy, DP and NP-hard. Tell them apart with the trap pairs.
  4. Test the idea on Sample Input 1: if the output does not match, the classification is wrong, not the example.

The observation that matters at the exam: the 5 problems are almost always variants of the same object. The text changes by one word and the paradigm changes completely. Read the goal and the constraints word by word.
