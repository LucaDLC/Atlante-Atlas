A.4 Facts to cite

  • Sum of the degrees = 2m (handshake lemma). Tree: connected and acyclic ⇔ connected with n − 1 arcs.
  • An undirected graph with m ≥ n edges has a cycle. Bipartite ⇔ no odd cycle.
  • DAG ⇔ there is a topological order ⇔ the DFS finds no back edge.
  • Cut property: the cheapest edge crossing a cut is in some MST (distinct weights). Cycle property: the most expensive edge of a cycle is in no MST.
  • Dijkstra is correct only with weights ≥ 0. A reachable negative cycle makes the shortest paths undefined.
  • S is a vertex cover ⇔ V \ S is an independent set: max IS + min VC = n. Clique in G = independent set in the complement.
  • Weak duality: val(f) ≤ cap(A, B) for every flow f and every cut. Max-flow min-cut: value of the maximum flow = capacity of the minimum cut.
  • Augmenting path theorem: f is maximum ⇔ there is no s → t path in the residual network. Integrality: integer capacities ⇒ integer maximum flow.
  • Menger: maximum number of arc-disjoint s–t paths = minimum number of arcs to remove to separate s from t.
  • Hall: a bipartite graph with |L| ≤ |R| has a matching covering L ⇔ |N(S)| ≥ |S| for every S ⊆ L. Kőnig: in a bipartite graph, minimum vertex cover = maximum matching.
  • P ⊆ NP. NP-complete = in NP and NP-hard. If an NP-complete problem is in P, then P = NP. Transitivity: X ≤p Y and Y ≤p Z ⇒ X ≤p Z.
  • Pseudo-polynomial: O(nW) is polynomial in W, not in log W. That is why knapsack has a DP and is still NP-complete.

A.7 Useful phrases (in English)

  • "in increasing / non-decreasing order of key"; "ties are broken arbitrarily".
  • "if and only if"; "without loss of generality"; "by induction on i".
  • "Given an instance of X, we construct an instance of Y as follows."; "a yes-instance of X is mapped to a yes-instance of Y".
  • "by the integrality theorem"; "by the max-flow min-cut theorem"; "an augmenting path in the residual network".
  • "the recurrence solves to"; "polynomial in the input size"; "pseudo-polynomial in W".

A.8 Times and checklist

4 hours = 240 minutes for 26–28 points. Initial reading and final re-reading about 15 minutes each. If a question gets stuck, write what you have and move on to the next.

  • I wrote which problem.
  • Greedy: explicit order with direction, admissibility test, time.
  • Graph: nodes, arcs, how many, directed, weights; algorithm with name and starting node; what I print.
  • DP: meaning of OPT, range, base cases, −∞ for the impossible, which cell is the answer, time and space.
  • Flow: network for Sample Input 1, capacities, meaning of the max flow, algorithm and time.
  • NP-hard: P2 ≤p P1 in the right direction, "Given an instance…", both directions, small example.
  • Every time is in the parameters of the text.
