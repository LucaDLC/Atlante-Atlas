Kattis and Red Scare

To be admitted to the exam you need the mandatory exercises: individual exercises on Kattis, corrected automatically, and a group project, Red Scare, in November. Without them the exam grade is NA.

The page "About this course" speaks of 10 mandatory items (9 Kattis + Red Scare); the official description of the course says "12 mandatory programming assignments". Check the "Standing on Kattis" status on LearnIT, which is what counts.

Dates from the LearnIT page of the course. Every Thursday from 11 to 12 the TA session serves to solve the Kattis problem of the week.

You can discuss with classmates and the TAs ("I've solved XYZ using ABC's algorithm, just make sure that Foo is always Baa"). You cannot publish code, have the exercise solved by others or by an artificial intelligence, nor pass off someone else's code as your own. If someone helped you, write it in a comment in the code you hand in ("Thanks to Alice Cooper for pointing me to…").

In the folder Algorithm Design there are your solutions to introductory exercises (Echo, Alice, Backspace, BaseP, Bto01), exhaustive search (Perket, Satisfaction), stable matching (Draft, and Matching still to finish), greedy (Greedy) and closest pair (PairPoints). The ones I have run give correct results; the "accepted" status, however, you only see on Kattis.

Red Scare

  • The text is in the repo thorehusfeldt/algdes-labs on GitHub (folder red-scare).
  • It is done in the delivery group, about 5 people, and handed in on LearnIT: code and report. It must not be discussed on the public forum.
  • "This exercise is about choosing between and using known algorithmic paradigms. It is not about implementing these paradigms": you may reuse code for known algorithms or take it from a library, declaring it in the report.
  • About three weeks of work. On 12 and 19 November the TA sessions are group feedback on the project (18 minutes per group): come with ideas on Few, Alternate and None.
  • Delivery: Friday 27 November, 23:59. Feedback by 3 December; if needed, a new delivery by 10 December.

Red Scare asks you to decide, for several questions on the same graph, which paradigm to use: BFS, DP on a DAG, flow, or "is NP-hard". It is exactly the classification work of the exam, on a bigger problem.
