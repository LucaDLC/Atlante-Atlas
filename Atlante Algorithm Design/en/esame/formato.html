What the exam is like inside

Structure stable from 2018 to 2023. There are 5 problems in Kattis style (text, input, output, examples) and 6 questions that ask you to recognise the paradigm and to defend the choice with a short, precise solution.

What the teacher wants to read

  • The book is admitted, and must be used. The teacher wants "I will use Dijkstra's algorithm [KT, p. …] to find …", not a reinvented algorithm.
  • Half a page per question. Short, correct answers beat long ones. Illegible handwriting is read against you.
  • Parameters of the problem, not a generic n. The time goes in the names of the text (N, K, R, T, d…). If you build a graph, say how many nodes and arcs it has as a function of those names.
  • Never "sort the input". Write what you sort and in which direction: "in increasing order of number of 1s".
  • Opening phrase for reductions: "Given an instance of BLABLA, we construct an instance of BLUB as follows."
  • Draw the Sample Input 1 when the question asks for it (graph or flow network): it is the fastest way to show that the model is right.

The time

240 minutes for the exam. Initial reading and final re-reading of about 15 minutes each. The rest is divided between the problems and the questions: a 5-point question takes about 30–35 minutes. If a question gets stuck, write what you have and move on to the next one: a partial answer is worth more than nothing.

Before handing in

  • I wrote which problem (question (a) is worth a point of its own).
  • Greedy: explicit order with direction, admissibility test, time.
  • Graph: nodes, arcs, how many, directed, weights; algorithm with name and starting node; what I print.
  • DP: meaning of OPT, range of the parameters, base cases, −∞ for the impossible, which cell is the answer, time and space.
  • Flow: network for Sample Input 1, capacities, meaning and value of the max flow, algorithm and time.
  • NP-hard: P2 ≤p P1 in the right direction, "Given an instance…", both directions, complete small example.
  • Every time is in the parameters of the text, not with a generic n.
