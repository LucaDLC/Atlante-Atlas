NP and NP-completeness

NP are the yes/no problems with a short certificate that can be verified in polynomial time. NP-complete means in NP and NP-hard. This page explains the two concepts and why the proof of NP-hardness is done with reductions.

P and NP: what it means

You work only with yes/no problems (the decision version). A class is a set of problems with the same difficulty.

P = the problems that are solved in polynomial time, O(nk) with fixed k. Examples: shortest path, matching, 2-SAT.
NP = the problems in which a solution is verified in polynomial time, if someone hands it to you. Examples: Vertex Cover, 3-SAT, Hamiltonian cycle.

The difference is finding versus checking. Sudoku: filling it in is difficult, checking an already filled sudoku is fast.

Every problem in P is also in NP (if you can solve it, you can also verify it): P ⊆ NP. It is not known whether the converse holds too: it is the question P = NP?, still open.

NP stands for nondeterministic polynomial, not for "not polynomial". Easy problems are inside NP.

The certificate

A problem is in NP if for every yes-instance there exists a certificate (a proof) of polynomial size, and a verifier checks it in polynomial time. Example: vertex cover of size k. Certificate: the k nodes. Verification: for each edge, one of the two endpoints is in the list. Time O(n + m).

Avoid or Lockout are in P, hence in NP. The question "is it in NP?" only asks to find the certificate.

NP-complete and Cook-Levin

NP-hard: at least as hard as every problem in NP. NP-complete: in NP and NP-hard. Cook-Levin theorem: Circuit-SAT is NP-complete. From there, through reductions, one obtains 3SAT, Independent Set, Vertex Cover, Hamiltonian cycle and many others.

Assuming P ≠ NP: if an NP-complete problem were in P, then P = NP. In the proofs you do not discuss the case P = NP.

At the exam

"Show that the problem is in NP": (a) decision version, (b) certificate and its length, (c) verification in polynomial time. Phrase for the correctness of an algorithm: "If the algorithm were correct, an NP-complete problem would be in P, so P = NP."
