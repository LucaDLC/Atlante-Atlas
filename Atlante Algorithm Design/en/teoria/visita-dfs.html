DFS: depth-first visit

The DFS (depth-first search, visit in depth) goes deeper as far as it can; when it is blocked it goes back. It serves to find cycles, connected components and the order of the nodes that feeds the topological sort.

The problem and the idea

The problem: explore everything that can be reached, and remember in which order the nodes were visited.

The idea: from the current node you go down to a neighbour not yet seen, and repeat. When a node has no more neighbours to visit it is finished, and the visit returns to the node from which it had come (the parent). The stack of recursive calls, or an explicit stack, keeps track of the current path.

Back edges and cycles

An arc from a node u to a node v already visited, which is not the parent of u, is called a back edge. In the undirected graph it means that a cycle exists.

The cycle is rebuilt by climbing the parents from u up to v. This is the simplest way to find a cycle in a graph: a DFS, stopping at the first back edge.

In the undirected graph the arc you have just travelled towards the parent is obviously already seen. It is not a cycle. Always check "seen and not the parent".

Connected components

A connected component is a group of nodes all reachable from each other. To count them you launch a visit from a non-visited node, marking everything you find; you repeat until no non-visited nodes remain. Each launch finds one component. Total cost: O(n + m), because each node and arc is seen only once.

Cost and when to use it

Cost O(n + m). Use the DFS for: cycles (back edges), connected components, topological order (the finish order, read backwards, see the dedicated page), reachability when you do not need the distance.

Do not use it for the minimum distance without weights: it finds a path, not the shortest one.

At the exam

For cycles or order of dependencies (prerequisites, order of computation) the answer is DFS, or topological sort. Write: "Run DFS from an arbitrary vertex. Every back edge found closes a cycle. Time O(n + m)."

For the distance it is not DFS: it is BFS (see the BFS page).
