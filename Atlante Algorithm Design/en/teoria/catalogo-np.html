Catalogue of hard problems

The NP-complete problems to use as P2 in the reductions. Choose the one with the structure most similar to your problem: independent set, cover, path through all the nodes, subset sum, colouring.

The catalogue

Decision problems, recognised from the wording of the text:

  • Independent Set (k nodes pairwise non-adjacent): "no two adjacent", "never at both ends of a wire".
  • Vertex Cover (k nodes touching every edge): "every wire monitored", "buy all tiles".
  • Set Cover (k sets whose union is everything): "fewest … whose union is everything".
  • 3SAT (clauses of three literals): "one of three wishes".
  • Hamiltonian cycle / path (cycle or path touching all the nodes): "simple path", "all".
  • 3-coloring, Clique, Subset sum / Partition (numbers to split exactly in two).

The special-case test

Before building the reduction, check that your P1 contains P2 as a special case: fix a parameter of P1 at the extreme value (k = 2, r = n, W = V, t = 0) and check whether you get exactly P2. It is the fastest way to choose the right P2.

The easy look-alikes

Every hard problem has a twin that looks the same but is solved in polynomial time. What changes is a detail: a cycle that passes through every node is hard, a cycle that passes through every edge is easy.

If the numbers of the problem are tiny and the problem "looks like a cover", the text leaves room for exhaustive search. At the exam, however, the structure decides, not the numbers: you must be able to say which known problem to reduce from.

At the exam

Choose P2 from the catalogue by looking at the structure: independent nodes → Independent Set; cover of edges → Vertex Cover; path over all nodes → Hamiltonian; exact sum → Subset sum. Common mistake: confusing the direction of the reduction.
