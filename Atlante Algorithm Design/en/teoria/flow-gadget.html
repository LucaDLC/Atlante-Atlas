Reducing to a flow: recipe and gadget

The flow puts capacities on the arcs, but the constraints usually concern the nodes: a node used at most once, or a vertex to remove. The split gadget turns a node constraint into an arc constraint.

Splitting the node

Replace the node v with two nodes v_in and v_out, joined by v_in → v_out with capacity c(v). The arcs that entered v now enter v_in; those that left it leave from v_out.

Every flow that passes through v must cross that arc: so it cannot exceed c(v). The cost doubles the nodes and adds n arcs: same order of magnitude.

Where it is used

Paths node-disjoint (each node used by only one path), minimum number of nodes to remove to separate s from t (node cut), and "special" nodes that cannot be removed (infinite capacity).

The recipe: reduce to a flow

For each problem you want to solve with the flow, answer five questions in order. It is the same recipe for matching, pairs and disjoint paths:

  1. The nodes: which and how many, as a function of the parameters of the problem. Usually: s, t, one node for each object of type A, one for each object of type B.
  2. The arcs: from where to where, oriented, and how many in total.
  3. The capacities: each with its meaning. Capacity 1 means "at most once". Capacity ∞ means "no limit, but the arc cannot be cut".
  4. The meaning of the flow: what a maximum flow means in the original problem, and what it is worth. It must be proved in both directions: from a solution a flow arises, and from an integer flow a solution arises.
  5. The time: which flow algorithm and with which parameters. Ford-Fulkerson costs O(m·C), where m are the arcs and C the maximum value of the flow.

Order of work: first draw the example graph, precisely on nodes, arcs and how many they are. Then write the general rule. Whoever skips the drawing almost always gets a capacity wrong.

At the exam

Constraint "a node at most once" → split of the node with capacity 1. Phrase: "Split each node v into v_in and v_out joined by an arc of capacity 1; arcs into v enter v_in, arcs out of v leave v_out."
