Divide and conquer: the method

Divide and conquer (divide and conquer) splits the problem into smaller independent parts of the same type, solves them recursively and recombines the results. The cost is read from the recurrence with the master theorem.

The method in six steps

  1. Divide: halves, quadrants, left and right of a line.
  2. Invariant: why the answer lies in the chosen part, or how you recombine the parts.
  3. Base case: n ≤ 1 (or n ≤ 2), written explicitly.
  4. Cost of dividing and recombining: usually O(n^c).
  5. Recurrence: T(n) = a·T(n/b) + O(n^c).
  6. Master theorem (fundamental theorem): compare c with log_b a.

Binary search

The simplest case: a sorted sequence, and the element to search for. At each step you look at the centre mid: the order tells you in which half the answer can lie, and you discard the other. The interval halves, so T(n) = T(n/2) + O(1), that is O(log n).

Signal in the exams: "faster than linear": you cannot read all the input, so you must discard half of it at each step.

The master theorem

Given T(n) = a·T(n/b) + Θ(n^c) with a ≥ 1, b ≥ 2, compare c with log_b a:

  • if c < log_b a: T(n) = Θ(n^(log_b a)) (the leaves dominate);
  • if c = log_b a: T(n) = Θ(n^c · log n) (each level weighs the same);
  • if c > log_b a: T(n) = Θ(n^c) (the root dominates).

The number of subproblems must be constant, and the extra work must be of the form n^c. An extra work of n log n, or subproblems of different size, require another analysis (unroll the recursion).

At the exam

For the time of a divide and conquer: write the recurrence, then the master theorem. Phrase: "T(n) = a·T(n/b) + O(n^c). Since log_b a = …, by the master theorem T(n) = Θ(…)."

Base case: always write it explicitly. Common mistake: forgetting the recombination work.
