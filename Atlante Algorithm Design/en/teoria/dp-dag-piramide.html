DP on trees and DAGs: the pyramid

When the path can be followed in only one direction (a pyramid, a DAG, a tree), the DP computes the best value from the bottom up. It is the Tower problem of the exam.

The problem

A pyramid of cells with numbers. From each cell you go down to the left or to the right until the bottom: you want the path with the maximum sum. There are no cycles, because you always go down: it is a DAG.

The recurrence

OPT(i, j) = value(i, j) + max( OPT(i+1, j), OPT(i+1, j+1) ), with the last row as base case. The answer is OPT(0, 0). For the path: always go down to the child with the greater OPT.

Cost and general form

Pyramid of N levels: O(N²) time and space. Generic DAG: O(n + m), computing in reverse topological order. The same form is Bellman-Ford: the counter of edges is the "row" of the table.

Longest path in a DAG

Points on a mountain, connected by slopes. Each slope goes from u to v only downhill and has a score c. You can start and stop wherever you like. You want the path with the highest sum of scores.

Three sentences of the text decide everything:

  • «start and end … at any point»: no fixed start. Each point can be the beginning, with value 0.
  • «maximum sum»: the longest path, not the shortest.
  • «all slopes go downhill» (no cycles): the graph is a DAG (directed acyclic graph, a directed graph without cycles).

The longest path in any graph is NP-hard (you will see it with the Hamiltonian path). On a DAG instead it is dynamic programming in polynomial time: the absence of cycles allows a computation order, the topological one.

I define OPT(i, v) = the score of the best path that arrives at v with at most i slopes.

OPT(0, v) = 0 for every v: without slopes, the helicopter left you at v.

OPT(i, v) = max( OPT(i−1, v), max over each slope (u, v, c) of OPT(i−1, u) + c )

The first term is "I do not use a last slope". The second is "I arrive at v with one more slope, from the point u". Answer: the maximum over v of OPT(n−1, v), because a path with n points uses at most n − 1 slopes. Time O(n·m), space O(n²) with the whole table.

Two slopes between the same points can have different scores (sample 2: 1→2 with score 2 and 1→2 with score 4). If you store them in a matrix voto[u][v], the second overwrites the first and you keep the last one read, not the best. With a list of arcs (from, to, cost) all the slopes remain, and the max chooses.

At the exam

Best path in a structure that can be followed in one direction → DP on DAG/pyramid. Phrase: "OPT(v) = value(v) + max{OPT(u) : (v,u) ∈ E}, with OPT(t) = value(t). Time O(n + m) in topological order."
