Topological sort

A topological sort puts the nodes of a DAG in a row, so that every edge goes from left to right. It is needed every time there are dependencies: prerequisites, orders of computation, chains of decisions.

The problem and the DAG

A DAG (directed acyclic graph) is a directed graph without cycles. A topological order is a sequence of all the nodes such that every edge u → v has u before v. It exists if and only if the graph is a DAG.

Example: courses with their prerequisites. A course can be followed only after its prerequisites, so the legal sequence is a topological order.

The method with the incoming degrees

The incoming degree (in-degree) of a node is the number of edges that enter it. Kahn's method:

  1. Compute the incoming degree of each node.
  2. Put in a list the nodes with degree 0 (the sources).
  3. Take one, write it in the order, and decrease by 1 the degree of its successors. Whoever reaches 0 enters the list.
  4. Repeat until the list is empty.

Why it works: in a DAG there is always at least one source, and removing it leaves a DAG. Cost O(n + m).

The method with the DFS

Alternative: do a DFS on the whole graph, and write each node when it finishes (when all its neighbours have been visited). Then read the list of finishes backwards: it is a topological order. If the DFS finds a back edge, the graph has a cycle.

The node that finishes last, in a DAG, is a source: no arc enters it from the rest of the graph that is not already finished. That is why it goes first in the reversed order.

When it exists

A topological order exists only in a DAG. If the graph has a cycle, no order can make all the arrows go from left to right: the nodes of the cycle would chase each other. Kahn's method notices it: at the end nodes remain unwritten.

At the exam

When the question speaks of order of dependencies, prerequisites or order of computation of a DP on a DAG, use the topological sort. Write the explicit order and the direction: "in topological order: each arc goes from an earlier to a later vertex."
