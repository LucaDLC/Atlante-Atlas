Dynamic programming: the method

Dynamic programming (DP) solves a problem by building the optimum from the optima of smaller subproblems, which repeat. Each subproblem is computed once and saved in a table.

When DP is needed

The natural greedy has a counterexample. But the optimum is built from optima of smaller subproblems that repeat. Signals:

  • an order in which the subproblems shrink: prefixes of a sequence, a DAG, a tree, a pyramid that is followed in one direction only;
  • a numerical budget that becomes an index of the table (knapsack);
  • the greedy fails, but the choices can be ordered.

The recipe in eight steps

  1. Look at the optimal solution from the end: what is the last decision? (in or out, which arc, which word).
  2. Define the subproblem in words, with the range of the parameters: OPT(i, w) for i ∈ {0…n}, w ∈ {0…W}.
  3. Check that it is enough: after the decision, is the rest a subproblem of the same type? If not, add a parameter.
  4. Recurrence: one case for each possible decision, then max or min.
  5. Base cases and edges. An impossible case is worth −∞ (if you maximise), not 0.
  6. Order of computation: by increasing index, or by increasing length, or by reverse topological order.
  7. Answer: which cell you read (OPT(n, W), or the maximum of a row).
  8. Time and space = number of subproblems × cost of one step. If you need the solution, traceback backwards.

Knapsack and the pseudo-polynomial

Knapsack: OPT(i, w) = max{ OPT(i−1, w), v_i + OPT(i−1, w − w_i) } (the second only if w_i ≤ w). Time and space O(nW): it is pseudo-polynomial, because W is a number and not its length in bits (log W). That is why knapsack remains NP-complete, despite having a DP.

The recurring templates

Six templates cover almost all the exams:

  1. take or skip along a sequence (non-adjacent coins, weighted interval scheduling);
  2. numerical budget (knapsack, subset sum, exact change);
  3. paths in a DAG or pyramid (Tower, Grave Robber, Bellman-Ford);
  4. longest chain in a partial order (after sorting);
  5. strings and prefixes (edit distance, words, palindromes);
  6. trees (vertex cover on a tree, spreading of a message).

At the exam

Definition of OPT with the ranges, recurrence, base cases, which cell is the answer, time and space. Phrase: "Let OPT(i, w) denote the maximum value using only items 1..i with budget w, for i ∈ {0..n} and w ∈ {0..W}. Base: OPT(0, w) = 0. The answer is OPT(n, W). Time and space O(nW)."

Traps: forgetting the range; writing 0 instead of −∞ for the impossible cases; not saying which cell you read.
