Ford-Fulkerson: the maximum flow

The maximum-flow problem: sending as much material as possible from a source s to a sink t, respecting the capacities of the arcs. Ford-Fulkerson solves it with augmenting paths in the residual network.

The network and the flow

A network is a directed graph with a source s, a sink t and a capacity c(e) ≥ 0 on each arc. A flow f assigns to each arc a value with 0 ≤ f(e) ≤ c(e), and at each node other than s and t what enters equals what leaves (conservation). The value of the flow is what leaves s.

The residual network

For each arc e = u → v with capacity c and flow f, the residual network contains: a forward arc u → v with capacity c − f (how much you can still send), and a backward arc v → u with capacity f (how much you can undo). The backward arc is what allows correcting a choice made before.

The method: augmenting paths

While there is a path s → t in the residual network, take its bottleneck (the minimum capacity along the path) and increase the flow by that amount. To find the path: BFS or DFS. When there is no path any more, the flow is maximum.

The theorem and the cost

Augmenting path theorem: a flow is maximum if and only if there is no path s → t in the residual network. Integrality: with integer capacities there is an integer maximum flow, and Ford-Fulkerson finds it. That is why a 0/1 flow is read as an assignment.

Cost O(m · |f*|): with integer capacities it depends on the value of the flow. With capacity 1: O(mn).

At the exam

When the question has assignments with limits, disjoint paths or a minimum cut, build a network and read the max flow. Phrase: "Build a flow network with source s and sink t. Arc capacities encode the limits. By the integrality theorem there is an integral maximum flow of value k, which is the answer. Ford–Fulkerson runs in O(m·|f*|)."
