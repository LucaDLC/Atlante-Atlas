Bellman-Ford: shortest paths with negative weights

Bellman-Ford finds the minimum cost from a source even with edges of negative weight. It is the same DP for paths in a DAG, with a counter of edges.

The idea: relax all the edges, n − 1 times

A simple shortest path has at most n − 1 edges. So it is enough to repeat n − 1 times: relax all the edges. Each round fixes paths one edge longer. Equivalent DP: OPT(i, v) = minimum cost from s to v with at most i edges.

Negative cycles

If a reachable cycle has negative total cost, the shortest path does not exist: every round lowers it again. Bellman-Ford detects it with one more round: if a distance still improves, there is a negative cycle.

The cost

O(n·m) time, O(n) space. Slower than Dijkstra, but it works with negative weights, which Dijkstra does not handle.

At the exam

Negative weights → Bellman-Ford; negative cycles → detect them with one more round. Phrase: "Relax all edges n−1 times; then one more pass detects a negative cycle. Time O(mn)."
