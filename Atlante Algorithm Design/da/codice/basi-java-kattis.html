Kode: hurtig læsning og output i Java

Kattis-programmets skabelon: BufferedReader, StringTokenizer, StringBuilder. Hver linje forklaret, og de syntaksnoter, du har brug for.

Startskabelonen

Næsten alle Kattis-opgaver har denne form: læs antallet af tilfælde, læs linjerne, beregn, udskriv.

  • import java.io.*; og import java.util.*;: stjernen importerer alle klasserne i pakken.
  • throws IOException: readLine() kan fejle, og Java kræver, at man angiver det.
  • Navnet på den offentlige klasse skal stemme med filnavnet: her Main.
