Kode: Ford-Fulkerson i Java

Det maksimale flow med augmenterende veje: matrix over de resterende kapaciteter, BFS på restnetværket, flaskehals og annullering af flowet.

Restnetværket

Den resterende kapacitet er en matrix: cap[u][v] er, hvor meget jeg stadig kan sende fra u til v. Egnet til små grafer.

  • static på klassens globale variabler: metoden main bruger dem uden at få dem sendt.

Augmenterende vej

En BFS i restnetværket finder en vej s→t. Flaskehalsen er den mindste kapacitet langs vejen: den mængde passerer.

  • for-løkken, der går op ad forældrene, går fra t til s: for at rekonstruere vejen baglæns.

Kør det

Eksempel på input og output (faktisk kompileret og kørt).

4 5 0 3
0 1 1
0 2 1
1 2 1
1 3 1
2 3 1

(output)
flusso massimo 2
