Kode: Bellman-Ford i Java

Korteste veje med negative vægte: n − 1 runder af relaksation over alle kanterne, og kontrollen for negativ kreds med en runde mere.

Relaksationsrunderne

Hver runde gennemløber alle kanterne. Efter n − 1 runder er afstandene endelige, hvis der ikke er negative kredse.

  • final på variablen: værdien ændrer sig ikke mere efter tildelingen.
  • De negative vægte er ikke et problem for Java: de er heltal ligesom de andre.

Den negative kreds

En runde mere: hvis en afstand stadig bliver bedre, findes der en negativ kreds, som kan nås fra kilden.

  • return inde i main afbryder programmet.

Kør det

Eksempel på input og output (faktisk kompileret og kørt).

4 5 0
0 1 4
0 2 5
1 2 -3
2 3 2
1 3 6

(output)
0 0
1 4
2 1
3 3
