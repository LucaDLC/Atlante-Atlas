Kode: Kruskal i Java

Det minimale udspændende træ i Java: kanter sorteret efter vægt, union-find med path compression og cykeltesten.

Find med path compression

Funktionen find går op til roden. Hver knude, den møder, kobles direkte til roden.

  • static på metoder og felter: klassen Main opretter ingen objekter, den bruger kun fælles variabler.

Kruskal

Jeg sorterer kanterne efter stigende vægt og tager dem, der forbinder forskellige komponenter.

  • long har 64 bit, int 32. Suffikset L i literaler gør dem til long: 1000000000L.
  • Kommentaren efter } er tilladt: koden og kommentaren kan stå på samme linje.
