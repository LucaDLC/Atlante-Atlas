Kode: grafer som nabolister

Hvordan man bygger en graf i Java, hvordan man beregner en knudes grad, og hvordan man tjekker en kant. Det er grundkoden, som BFS, DFS og topologisk sortering hviler på.

Læsning af grafen

Grafen kommer som tekst: første linje n m, derefter m linjer med kanterne. Jeg gemmer den som en naboliste: en liste over naboerne for hver knude.

  • import java.io.*; og import java.util.*; importerer alle klasserne i de to pakker.
  • throws IOException: readLine() kan fejle, og Java kræver, at man angiver det (en checked-undtagelse).
  • new ArrayList<>(): diamanten <> siger til Java, at den skal udlede typen ud fra konteksten.

Grad og spørgsmålet om kanten

Graden af u er størrelsen af dens liste. At tjekke kanten u–v betyder at lede efter v i listen over u: det koster graden af u.

  • .size() er antallet af elementer i en liste; .length bruges kun til arrays.
  • int u = 0, v = 3; erklærer flere variabler af samme type på én linje.

Kør det

Eksempel på input og output (faktisk kompileret og kørt).

4 4
0 1
0 3
1 2
2 3

(output)
n = 4, m = 4
grado(0) = 2
grado(1) = 2
grado(2) = 2
grado(3) = 2
arco 0-3: true
