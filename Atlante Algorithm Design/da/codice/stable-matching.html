Kode: Gale-Shapley i Java

Forslagsalgoritmen i Java: præferencer som arrays, rang for modtagerne, kø af de frie forslagsstillere.

Præferencer og rang

Hver forslagsstiller har en liste over præferencer. Hver modtager har derimod brug for et hurtigt spørgsmål: hvem foretrækker jeg af to? Derfor bygger jeg rangen.

  • StringTokenizer læser heltallene på en linje; trim() fjerner mellemrummene i linjens kanter.

Forslagsløkken

Så længe der er en fri forslagsstiller, foreslår denne den næste modtager på listen. Modtageren afgør, om den vil beholde ham.

  • partnerDi[r] == -1: værdien -1 betyder "fri", fordi de rigtige indeks går fra 0 til n−1.

Kør det

Eksempel på input og output (faktisk kompileret og kørt).

3
0 1 2
1 0 2
0 1 2
2 0 1
0 1 2
0 1 2

(output: proponente - ricevente)
0 - 1
1 - 2
2 - 0
