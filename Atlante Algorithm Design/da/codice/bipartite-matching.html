Kode: bipartit matching i Java

Det største matching med augmenterende veje (Kuhns version, svarende til flow): rekursion med et array over de besøgte knuder.

Rekursiv augmenterende vej

For hvert element i L leder jeg efter en ledig modtager, eller jeg flytter den nuværende partner over til et andet valg.

  • || er det logiske "eller" med kortslutning: hvis den første er sand, kaldes den anden (rekursionen) ikke.

Kør det

Eksempel på input og output (faktisk kompileret og kørt).

3 3 5
0 0
0 1
1 0
2 1
2 2

(output)
matching massimo 3
