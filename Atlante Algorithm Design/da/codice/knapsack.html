Kode: knapsack i Java

Knapsack-tabellen opt[i][w] i Java: udfyldning række for række, og traceback for at rekonstruere de valgte objekter.

Tabellen

Tabellen har (n + 1) × (W + 1) celler. Række 0 og kolonne 0 er grundtilfældene: Java initialiserer dem selv til 0.

  • Math.max(a, b) er biblioteksfunktionen: der er ikke brug for at skrive if i hånden.
  • Den ydre løkke på i og den indre på w respekterer beregningens rækkefølge: hver celle afhænger kun af rækker, der allerede er beregnet.

Traceback: hvilke objekter

Jeg starter fra den sidste celle og går op igen. Hvis cellen er forskellig fra rækken over, blev objekt i taget, og budgettet falder.

  • Collections ligger i java.util: reverse, sort, max er hjælpefunktioner til lister.

Kør det

Eksempel på input og output (faktisk kompileret og kørt).

3 6
1 1
2 6
5 18

(output)
valore 19, oggetti [1, 3]
