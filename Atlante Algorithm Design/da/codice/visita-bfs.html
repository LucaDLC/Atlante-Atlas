Kode: BFS i Java

Den komplette BFS: afstande fra en kilde i en graf uden vægte. Hver linje forklaret, og de syntaksnoter, der skal til for at skrive den.

BFS med køen

Køen er en ArrayDeque: add sætter bagerst, poll fjerner forrest. dist[v] = -1 betyder "ikke set endnu", og knuden markeres, når den kommer i køen.

  • Integer → int i int u = coda.poll();: den automatiske konvertering kaldes unboxing.
  • ArrayDeque er hurtigere end LinkedList som kø; den accepterer ikke null.
  • StringBuilder samler teksten og udskriver den kun én gang: at udskrive linje for linje ved store output er langsomt.
