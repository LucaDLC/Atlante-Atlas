Kode: DFS i Java

Den rekursive DFS: besøg, besøgsrækkefølge, sammenhængende komponenter og opdagelse af cykler. Med syntaksnoterne om statiske felter og rekursion.

Det rekursive besøg

DFS er en funktion, der kalder sig selv på de naboer, der ikke er set. Systemets kaldstak udfører stakkens arbejde.

  • static: feltet eller metoden hører til klassen, ikke til objektet. Her er main static, så alt, den bruger, er static.
  • ! er negation; et boolean[] initialiseres helt til false.
  • I Java er rekursionens dybde begrænset: på grafer med millioner af knuder skal der en eksplicit stak til.

Sammenhængende komponenter

Den ydre løkke starter en DFS fra hver knude, der endnu ikke er set. Hver start er en ny komponent.

  • componenti++ er componenti = componenti + 1.

Kør det

Eksempel på input og output (faktisk kompileret og kørt).

5 5 0
0 1
1 2
2 3
3 1
0 4

(output)
componenti: 1
ciclo: sì
ordine di visita: 0=1 1=2 2=3 3=4 4=5
