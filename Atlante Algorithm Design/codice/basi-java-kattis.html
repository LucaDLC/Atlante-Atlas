Codice: lettura veloce e output in Java

Il modello di programma Kattis: BufferedReader, StringTokenizer, StringBuilder. Ogni riga spiegata, e le note di sintassi che servono.

Il modello di partenza

Quasi ogni esercizio Kattis ha questa forma: leggi il numero di casi, leggi le righe, calcola, stampa.

  • import java.io.*; e import java.util.*;: l'asterisco importa tutte le classi del pacchetto.
  • throws IOException: readLine() può fallire, e Java obbliga a dichiararlo.
  • Il nome della classe pubblica deve coincidere con il nome del file: qui Main.
