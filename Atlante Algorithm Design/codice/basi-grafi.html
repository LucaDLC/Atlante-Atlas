Codice: grafi come liste di adiacenza

Come si costruisce un grafo in Java, come si calcola il grado di un nodo, come si verifica un arco. È il codice di base su cui poggiano BFS, DFS e il topological sort.

Leggere il grafo

Il grafo arriva come testo: prima riga n m, poi m righe con gli archi. Lo memorizzo come lista di adiacenza: una lista di vicini per ogni nodo.

  • import java.io.*; e import java.util.*; importano tutte le classi dei due pacchetti.
  • throws IOException: readLine() può fallire, e Java obbliga a dichiararlo (eccezione checked).
  • new ArrayList<>(): il diamante <> dice a Java di dedurre il tipo dal contesto.

Grado e domanda sull'arco

Il grado di u è la dimensione della sua lista. Verificare l'arco u–v vuol dire cercare v nella lista di u: costa il grado di u.

  • .size() è il numero di elementi di una lista; .length è solo per gli array.
  • int u = 0, v = 3; dichiara più variabili dello stesso tipo in una riga.

Eseguirlo

Esempio di input e di output (compilato e lanciato davvero).

4 4
0 1
0 3
1 2
2 3

(output)
n = 4, m = 4
grado(0) = 2
grado(1) = 2
grado(2) = 2
grado(3) = 2
arco 0-3: true
