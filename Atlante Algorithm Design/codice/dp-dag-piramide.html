Codice: piramide (Tower) in Java

La DP dal basso verso l'alto su una piramide: array a righe di lunghezza crescente, e il massimo dei due figli.

Leggere la piramide

Ogni livello r ha r + 1 valori: un array di lunghezza variabile per riga.

  • new int[n][] lascia vuote le righe: si dimensionano dopo. È il modo di avere array frastagliati.

Risalire la piramide

L'ultima riga è il caso base. Ogni riga sopra prende il valore più il massimo tra i due figli.

  • Servono solo due righe in memoria in ogni momento: la riga nuova sostituisce la vecchia.

Eseguirlo

Esempio di input e di output (compilato e lanciato davvero).

3
1
1 2
2 0 0

(output)
massimo 4
