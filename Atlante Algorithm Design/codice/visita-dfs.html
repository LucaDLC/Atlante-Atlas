Codice: DFS in Java

La DFS ricorsiva: visita, ordine di visita, componenti connesse e rilevamento dei cicli. Con le note di sintassi di campi statici e ricorsione.

La visita ricorsiva

La DFS è una funzione che chiama sé stessa sui vicini non visti. La pila di chiamate del sistema fa il lavoro della pila.

  • static: il campo o il metodo appartiene alla classe, non all'oggetto. Qui main è static, quindi tutto ciò che usa è static.
  • ! è la negazione; boolean[] si inizializza tutto a false.
  • In Java la profondità della ricorsione è limitata: su grafi di milioni di nodi serve una pila esplicita.

Componenti connesse

Il ciclo esterno fa partire una DFS da ogni nodo non ancora visto. Ogni partenza è una nuova componente.

  • componenti++ è componenti = componenti + 1.

Eseguirlo

Esempio di input e di output (compilato e lanciato davvero).

5 5 0
0 1
1 2
2 3
3 1
0 4

(output)
componenti: 1
ciclo: sì
ordine di visita: 0=1 1=2 2=3 3=4 4=5
