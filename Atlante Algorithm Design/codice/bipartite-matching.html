Codice: matching bipartito in Java

Il matching massimo con cammini aumentanti (la versione di Kuhn, equivalente al flusso): ricorsione con un array di visitati.

Cammino aumentante ricorsivo

Per ogni elemento di L cerco un ricevente libero, oppure sposto il partner attuale su un'altra scelta.

  • || è il "o" logico con valutazione corta: se il primo è vero, il secondo (la ricorsione) non viene chiamato.

Eseguirlo

Esempio di input e di output (compilato e lanciato davvero).

3 3 5
0 0
0 1
1 0
2 1
2 2

(output)
matching massimo 3
