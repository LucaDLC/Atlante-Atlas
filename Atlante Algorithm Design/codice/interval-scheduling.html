Codice: interval scheduling in Java

Earliest finish time in Java: un array di intervalli, un ordinamento con una lambda, e la scansione greedy.

Leggere e ordinare

Ogni intervallo è un array di due interi, {inizio, fine}. Ordino l'array di array per la fine.

  • Integer.compare(a, b) restituisce −1, 0 o 1. Non usare a − b: con numeri grandi va in overflow e il confronto diventa sbagliato.
  • Una lambda è una funzione senza nome passata come argomento: qui implementa l'interfaccia Comparator.

La scansione greedy

Scorro gli intervalli in ordine di fine. Preso uno, aggiorno la fine dell'ultimo preso.

  • String.join(" ", scelti) unisce gli elementi di una lista con un separatore.
  • "[" + c[0] + ",": la concatenazione con + converte gli int in testo.
