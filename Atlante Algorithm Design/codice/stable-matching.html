Codice: Gale-Shapley in Java

L'algoritmo delle proposte in Java: preferenze come array, rango dei riceventi, coda dei proponenti liberi.

Preferenze e rango

Ogni proponente ha una lista di preferenze. Ogni ricevente, invece, serve una domanda veloce: chi preferisco tra due? Per questo costruisco il rango.

  • StringTokenizer legge gli interi di una riga; trim() toglie gli spazi ai bordi della riga.

Il ciclo delle proposte

Finché c'è un proponente libero, questi propone al ricevente successivo della sua lista. Il ricevente decide se tenerlo.

  • partnerDi[r] == -1: il valore -1 indica "libero", perché gli indici veri vanno da 0 a n−1.

Eseguirlo

Esempio di input e di output (compilato e lanciato davvero).

3
0 1 2
1 0 2
0 1 2
2 0 1
0 1 2
0 1 2

(output: proponente - ricevente)
0 - 1
1 - 2
2 - 0
