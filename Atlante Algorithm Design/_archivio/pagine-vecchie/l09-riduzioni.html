La riduzione

X ≤p Y ("X si riduce polinomialmente a Y") se ogni istanza di X si può risolvere con un numero polinomiale di passi più un numero polinomiale di chiamate a un risolutore di Y. Di solito una sola chiamata: trasformo l'istanza e chiedo a Y.

Y si risolve in tempo polinomialeanche X

X ≤p Y e Y ≤p ZX ≤p Z (transitività)

Tre strategie di riduzione (le slide)

1. Equivalenza semplice: Independent Set ≡ Vertex Cover

Independent set: nodi senza archi tra loro. Vertex cover: nodi che toccano ogni arco.

2. Caso particolare → caso generale: Vertex Cover ≤p Set Cover

Ogni arco diventa un elemento dell'universo U; ogni nodo v diventa l'insieme degli archi che tocca. Scegliere k nodi che toccano tutti gli archi = scegliere k insiemi che coprono U. Vertex cover è un caso speciale di set cover. La prova completa, nel formato del corso, è in scrivere una prova.

3. Gadget: 3-SAT ≤p Independent Set

3-SAT: una formula in cui ogni clausola è un "or" di 3 letterali (variabili o negazioni), e tutte le clausole devono essere vere. Si costruisce un grafo con un pezzo (gadget) per ogni clausola.

Da qui, per transitività: 3-SAT ≤p Independent Set ≤p Vertex Cover ≤p Set Cover.
