Scrivere una prova di NP-hardness

All'esame la domanda 6 vale 5 punti in quattro parti: quale problema, da quale problema noto, e la riduzione. Il docente ha scritto un modello da seguire ("How to NP-Hardness", ottobre 2025): usarlo evita l'errore più grave, la freccia al contrario.

Il modello del corso

Claim: Some Problem is NP-hard.

Proof. We will reduce from Other Problem, which is known to be NP-hard.

Let … be an instance of Other Problem. Construct an instance … of Some Problem as follows. (…)

For example, if … is an instance to Other Problem then the resulting instance to Some Problem is ….

(Note that the size of … is polynomial in the size of ….)

Now let … be a solution to Some Problem for the instance …. [then it gives a solution to Other Problem]. Conversely, if … is a solution to Other Problem, then ….

Esempio del corso: Vertex Cover ≤p Set Cover

Claim: Set Cover is NP-hard. Proof. We will reduce from Vertex Cover, which is known to be NP-hard. Let G, k be an instance of Vertex Cover, with vertices v₁, …, vₙ and edges e₁, …, eₘ. Construct an instance U, F, k' of Set Cover as follows: U = {1, …, m}, F = {S₁, …, Sₙ} where Sᵢ contains the indices of the edges incident on vᵢ, and k' = k. The resulting instance has size O(m + n). If a subfamily of k' sets covers U, the corresponding vertices touch every edge, so they form a vertex cover of size k. Conversely, a vertex cover C of size k gives the k sets Sᵢ for vᵢ ∈ C, which cover every edge index.

Svolto: esame 21 dicembre 2023, domanda 6

I cinque problemi sono Bit Shelter, Cluster, Decrease, Expensive Ones, To Xor Or Not To Xor. Cluster è graph traversal (BFS), Decrease è DP (longest path in un DAG), Expensive Ones è greedy, To Xor è flusso (svolto). Resta:

DomandaRisposta
(a) Which problem is NP-hard? (P1)Bit Shelter: scegliere il minimo numero di bitstring il cui or dà tutti 1
(b) Which well-known NP-hard problem? (P2)Set Cover: ogni bitstring è l'insieme delle posizioni in cui ha 1
(c) P1 ≤p P2 or P2 ≤p P1?P2 ≤p P1: Set Cover ≤p Bit Shelter

"Given an instance U = {1, …, K}, F = {S₁, …, S_N} of Set Cover, we construct an instance of Bit Shelter with N bitstrings of length K: bitstring i has a 1 in position j if and only if j ∈ Sᵢ. [Example above.] The construction takes O(NK) time. A set of bitstrings has bitwise-or 1…1 exactly when the corresponding sets cover every element of U, so a minimum solution of Bit Shelter gives a minimum set cover, and conversely.

Two details: Bit Shelter guarantees that the or of all strings is 1…1 and that the strings are distinct. So we first check in polynomial time whether the union of F is U (if not, the Set Cover answer is simply 'no'), and we remove duplicate sets, which does not change the optimum."

La riduzione deve funzionare per ogni istanza del problema noto. Se l'istanza di Set Cover non soddisfa le garanzie dell'input di Bit Shelter (unione non completa, insiemi ripetuti), la trasformazione non produrrebbe un input valido. Notarlo e sistemarlo è il tipo di precisione che il docente chiede.
