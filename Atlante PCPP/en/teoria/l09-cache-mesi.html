Week 9 · Performance

Cache and coherence: the MESI protocol

The CPU is faster than the RAM, and the cache closes the gap. With several cores each cache has a copy of the data, and the copies must agree: that is the job of the MESI protocol.

The bridge between CPU and RAM

The CPU works much faster than the RAM. The cache is a small, fast memory, close to the CPU, that keeps copies of the data used recently. It works well because of locality of access: if a datum is needed now, it will probably be needed again, and data close together in memory are often needed together.

More cores, more caches

Each core has its own caches. The same memory address can therefore be in several caches at the same time. The block of memory that a cache copies is called a cache line: usually 64 bytes. The caches must agree on the value of each line: the mechanism is called a coherence protocol, and in the slides it is MESI, from the name of its four states.

The MESI states

Each cache line, in each core, is in one of four states:

statemeaningis the RAM up to date?
M Modifiedmodified copy, present only in this cacheno: the RAM has the old value
E Exclusiveunmodified copy, present only hereyes
S Sharedunmodified copy, present in several cachesyes
I Invalidthe line is not valid: it must be read again–

To write to a line in state S, the core must first send an invalidate message to the other caches, and wait for their confirmation (ack). Only then does the line become M.

Fast or slow

The speed depends on what the core wants to do and on the state of the line in its cache. The most important rows of the slide:

What follows for the code

The cost is not in the computation, it is in the movement of the lines between caches. A datum written only by one thread stays in M in its cache: fast. A datum written by several threads goes back and forth: slow.
If you have used only threads without thinking about memory, this is the part you are missing: there is not one single "value" in memory, there are copies in several caches that must agree.
