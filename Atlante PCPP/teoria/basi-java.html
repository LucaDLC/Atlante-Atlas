Java per la concorrenza

Il minimo di Java che serve per leggere il codice del corso: creare e avviare un thread, aspettarlo, cosa cambia tra static e non, e come si lancia un esercizio con Gradle (anche da PowerShell).

Tre modi di scrivere un thread

Un thread è una sequenza di istruzioni che avanza in modo concorrente alle altre: a pezzi mescolati su un core, oppure davvero in parallelo su più core. In Java il comportamento del thread si scrive nel metodo run().

start() e join()

turnstile.run() non crea un thread: esegue run() come un metodo normale, nel thread che lo chiama. Per la concorrenza serve start().

join() può lanciare InterruptedException (se qualcuno interrompe il thread in attesa). È un'eccezione controllata: Java obbliga a gestirla con try { … } catch (InterruptedException e) { … } o a dichiararla con throws. Lo stesso vale per await(), wait(), sleep(), acquire().

Perché il codice delle lezioni sta nel costruttore

Nel codice delle lezioni il main fa quasi niente: crea un oggetto, e tutto il lavoro sta nel costruttore. Il motivo è una regola di Java: main è static, quindi non appartiene a nessun oggetto e non vede i campi d'istanza. Mettendo i campi condivisi (il contatore, il lock) in un oggetto, e i thread in una classe interna, tutti i thread vedono gli stessi campi.

static contro istanza

Campo d'istanza

class Conto { int saldo; }
Conto a = new Conto();
Conto b = new Conto();

Ogni oggetto ha il suo saldo: a.saldo e b.saldo sono due variabili diverse.

Campo static

class Conto { static int totale; }
Conto a = new Conto();
Conto b = new Conto();

C'è una sola totale per tutta la classe, condivisa da tutti gli oggetti.

Conta molto per i lock: synchronized su un metodo d'istanza usa il lock dell'oggetto, su un metodo static usa il lock della classe. Sono due lock diversi: vedi synchronized (esercizio 2.3).

Lanciare un esercizio con Gradle

Comando (dalla cartella week01exercises)Cosa fa
gradle compileJavacompila tutto app/src/main/java
gradle -PmainClass=exercises01.TestLongCounterExperiments runcompila ed esegue la classe indicata (bash, macOS, Linux)
gradle "-PmainClass=exercises01.TestLongCounterExperiments" runla stessa cosa in PowerShell: servono le virgolette
 
PS> gradle -PmainClass=lecture01.CounterThreads run
Task '.CounterThreads' not found in root project 'lecture01' and its subprojects.
PowerShell spezza il parametro al punto e Gradle riceve .CounterThreads come nome di un task. Metti tutto il parametro tra virgolette: gradle "-PmainClass=lecture01.CounterThreads" run (lo dice anche la guida Gradle del corso).

I file vanno in app/src/main/java/exercises01/ e la prima riga di ogni file è package exercises01;. Il nome della classe con main è quello che passi a -PmainClass, preceduto dal package.
