Java til samtidighed

Det minimum af Java, der skal til for at læse kursets kode: oprette og starte en tråd, vente på den, hvad der ændrer sig mellem static og ikke, og hvordan man starter en øvelse med Gradle (også fra PowerShell).

Tre måder at skrive en tråd på

En tråd er en følge af instruktioner, der skrider frem samtidig med de andre: i blandede stykker på én kerne, eller rigtig parallelt på flere kerner. I Java skrives trådens adfærd i metoden run().

start() og join()

turnstile.run() opretter ikke en tråd: den kører run() som en almindelig metode, i den tråd der kalder den. Til samtidighed skal du bruge start().

join() kan kaste InterruptedException (hvis nogen afbryder den tråd, der venter). Det er en kontrolleret undtagelse: Java tvinger dig til at håndtere den med try { … } catch (InterruptedException e) { … } eller til at angive den med throws. Det samme gælder for await(), wait(), sleep(), acquire().

Hvorfor koden fra forelæsningerne står i konstruktøren

I forelæsningernes kode gør main næsten intet: det opretter et objekt, og alt arbejdet ligger i konstruktøren. Grunden er en Java-regel: main er static, så den hører til intet objekt og ser ikke instansfelterne. Ved at lægge de delte felter (tælleren, låsen) i et objekt, og trådene i en indre klasse, ser alle trådene de samme felter.

static over for instans

Instansfelt

class Conto { int saldo; }
Conto a = new Conto();
Conto b = new Conto();

Hvert objekt har sin egen saldo: a.saldo og b.saldo er to forskellige variable.

Statisk felt

class Conto { static int totale; }
Conto a = new Conto();
Conto b = new Conto();

Der er kun én totale for hele klassen, delt af alle objekterne.

Det betyder meget for låse: synchronized på en instansmetode bruger låsen på objektet, på en static-metode bruger den låsen på klassen. Det er to forskellige låse: se synchronized (øvelse 2.3).

Start af en øvelse med Gradle

Kommando (fra mappen week01exercises)Hvad den gør
gradle compileJavakompilerer alt i app/src/main/java
gradle -PmainClass=exercises01.TestLongCounterExperiments runkompilerer og kører den angivne klasse (bash, macOS, Linux)
gradle "-PmainClass=exercises01.TestLongCounterExperiments" rundet samme i PowerShell: anførselstegnene er nødvendige
 
PS> gradle -PmainClass=lecture01.CounterThreads run
Task '.CounterThreads' not found in root project 'lecture01' and its subprojects.
PowerShell spezza il parametro al punto e Gradle riceve .CounterThreads come nome di un task. Metti tutto il parametro tra virgolette: gradle "-PmainClass=lecture01.CounterThreads" run (lo dice anche la guida Gradle del corso).

Filerne ligger i app/src/main/java/exercises01/, og første linje i hver fil er package exercises01;. Navnet på klassen med main er det, du giver til -PmainClass, med pakken foran.
