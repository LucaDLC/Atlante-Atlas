Concetti chiave

sequential consistency
preserva il program order intra-thread e le operazioni appaiono avvenire istantaneamente, in un ordine totale visto da tutti.
memory model
regole a livello di linguaggio che determinano quali esecuzioni di un programma sono valide, su qualunque hardware.
azione
coppia t(o): il thread che esegue e l’operazione eseguita. Un evento di esecuzione, non una riga di codice.
program order
ordine totale delle azioni dentro un singolo thread. Non dice nulla fra thread diversi.
synchronizes-with
lista chiusa di regole che creano archi fra thread diversi: start, join, lock/unlock, accessi volatile.
happens-before
chiusura transitiva di program order ∪ synchronizes-with. Non è ordine temporale: è garanzia di visibilità.
