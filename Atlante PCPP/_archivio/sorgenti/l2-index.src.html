Concetti chiave

monitor
stato condiviso più operazioni che lo proteggono dalla corruzione anche se eseguite concorrentemente. In Java si realizza come classe.
condition variable
coda dove il monitor mette i thread ad aspettare. Da non confondere con la condizione di un if o di un while.
entry queue
thread che aspettano il lock per entrare nel monitor.
semantica Mesa
i thread svegliati tornano a competere nella entry queue. È quella di Java — per questo la guardia è un while.
fairness
in questo corso significa assenza di starvation, non ordine FIFO.
visibility
se e quando la scrittura di un thread diventa osservabile da un altro.
volatile
garantisce visibility e impedisce il reordering. Non garantisce mutua esclusione.
